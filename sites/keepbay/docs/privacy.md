# 隐私与安全 {#privacy}

本页说明 Keepbay 什么时候联网、发送什么、记录什么，以及在登录、文件访问、文件处理上做了哪些安全措施。

Keepbay 没有做端到端加密。文件存放在您自己的硬盘上（或者您自己选择的远程存储上）。服务端需要为文件生成缩略图、提取文字、交给 AI 分析，如果文件经过加密，这些处理都无法进行。

因此我们不使用"零知识""只有您能看到"这类表述。我们能承诺的是以下几点：

- 数据只在您自己的服务器或 NAS 上，不经过我们；用了远程文件夹的，文件在您自己选的远程存储上
- AI 默认在本地处理；用云端模型时，界面上写明会发送什么、发给谁，由您决定
- 登录、下载、分享和每一次 AI 调用都有记录，您可以查看
- 不收集任何数据，没有统计和追踪

## Keepbay 什么时候联网 {#outbound}

程序里没有统计、遥测、崩溃上报。网页也不加载任何第三方的脚本、字体或图片，页面的 CSP 只允许连接自己；添加了 S3 兼容存储的[远程文件夹](./remote-folders#transfer)、用浏览器直连的，会加上这些存储的地址。

Keepbay 只在以下情况主动访问外网，其中大部分需要您手动操作后才会发生：

| 情况 | 连到哪里 | 发送什么 |
|---|---|---|
| 检查更新（默认每天一次，可关闭） | 授权中心 `huohuastudio.com` | 产品名称、是否接收测试版 |
| 在线更新 | 授权中心，再到它给的下载地址 | 产品名称、安装 ID（换取下载链接） |
| 激活专业版、自动续期 | 授权中心 | 授权码、安装 ID、产品名称 |
| 下载本地模型 | ModelScope、Hugging Face、GitHub | 普通的下载请求 |
| 云端 AI | 您添加的 AI 厂商 | 见 [AI](#ai) |
| 远程文件夹 | 您添加的对象存储、WebDAV 服务或 SFTP 服务器 | 列出、读写文件的请求 |
| 外部帐号登录 | 您配置的身份提供方 | 标准的 OIDC 流程 |
| 通知 | Bark 服务器、您的 SMTP 服务器 | 通知的标题和正文 |
| 离线下载 | 您给的网址、BT 网络、yt-dlp 访问的网站 | 下载请求 |
| 测试代理 | GitHub、Hugging Face | 只读响应头 |
| 获取自定义的模型清单（只在用 `--model-manifest` 或环境变量 `KEEPBAY_MODEL_MANIFEST` 指定了地址时；所有者打开「AI 模型」设置时，最多每小时一次） | 您指定的地址 | 普通的请求 |

安装 ID 是首次启动时生成的随机 UUID，不含任何硬件信息，用来让授权中心知道"这是同一台设备"。

授权证书在本地验签，平时不需要联网。开着自动续期时，到期时间或更新服务截止日的前后 7 天内，每天最多联网尝试续期一次；安装的版本超出更新服务范围时，也会每天尝试一次。

如果不希望 Keepbay 为续期联网，可以在授权页关闭自动续期。在无法联网的设备上，也可以手动导入证书，全程不联网。

其中的 HTTP 请求都使用「系统设置 › 网络」中的代理设置（默认跟随 `HTTPS_PROXY` 等环境变量），地址在局域网内的始终直连。

发邮件用的 SMTP 连接，和 BT 下载的部分连接（如 UDP tracker、和其他节点之间的连接），不经过这个代理，直接联网。

## AI {#ai}

AI 功能属于专业版。我们的原则是**能在本地处理的，就在本地处理**。

语义搜索、以图搜图、识别图片中的文字都有本地模型，下载后在您的设备上运行，不向外发送任何数据。其中按画面搜图和识别图片中的文字目前只能使用本地模型，照片不会发送到云端。

对话、语义搜索和下面几项后台功能，用不用云端模型由所有者决定。

接口地址在局域网内的（比如家里另一台机器上的 Ollama）视为本地；其余视为云端，必须使用 HTTPS。

用云端模型时，「系统设置 › AI 模型」中每项功能都写明会发送什么：

| 功能 | 用云端模型时发送 |
|---|---|
| AI 桌面 | 您输入的文字和您让它查看的文件内容，详见 [AI 桌面](./ai-desk#privacy) |
| 语义搜索 | 文件中的文字和您的搜索词 |
| 自动整理 | 文件名、大小、日期和文件中的一段文字，以及可以放进去的文件夹的路径 |
| AI 标签 | 文件名、修改日期和文件中的一段文字，以及您建的标签名 |
| 日期提醒 | 文件名和到期日附近的几句原文 |

后三项在后台自动处理文件，风险最高，因此多设了一道确认：选择云端模型后不会立即发送，需要所有者在「后台功能用云端模型」中逐项允许。更换厂商后需要重新允许。

语义搜索的索引也在后台建立，但没有这道确认。选择云端的文本向量模型后，文件中进入语义索引的文字会发送给厂商转换为向量，请在选择前确认，见[语义搜索](./semantic-search#cloud-embedding)。

成员默认不能使用云端 AI。如果这项功能配置的是云端模型，成员在 AI 桌面提问会被拒绝，搜索时也不会返回按意思找到的结果。所有者可以在成员详情中打开。

这个开关只针对成员自己发起的调用。收件箱整理、AI 标签、日期提醒等后台处理不属于某个成员发起的调用，是否使用云端模型只取决于所有者的设置和上面的逐项允许。

每一次实际发出的 AI 调用都记在「系统设置 › AI 模型 › 调用记录」中：谁发起的、哪项功能、哪个模型、发送了哪类数据、多少字节、多少 token、产生了多少费用。不保存内容本身（调用失败时会记下厂商返回的错误说明，其中可能带有一小段内容），保留 400 天。

还可以设置每月花费上限。费用根据您填写的单价和厂商返回的 token 数估算，单价填写正确时估算才准确；多个调用同时进行时，花费可能略微超出上限。实际费用以厂商的账单为准。

## 访问记录 {#access-log}

「系统设置 › 访问记录」记录这些操作：

- 登录，包括成功和失败、用的什么方式
- 下载和打包下载
- 创建分享链接、离线下载
- 分享链接的访客打开、输入密码、浏览、下载

每条记录时间、用户、IP、浏览器和结果，保留 180 天，只有所有者能看。

浏览和预览不记录，否则浏览文件夹会产生大量记录，需要查找的记录反而难以找到。

登录时输入了不存在的用户名，也不记这个用户名，因为用户常会把密码误输入用户名框。

## 密钥和加密 {#encryption}

- **登录密码**：argon2id 哈希（64 MiB 内存、3 轮），数据库中没有明文
- **会话**：随机 256 位令牌，数据库只存哈希
- **其他敏感配置**：AI 厂商的 API Key、两步验证密钥、外部登录的 client_secret、远程存储的访问密钥和密码、通知渠道和代理的密码，用数据目录中的 `secret.key` 加密（AES-256-GCM）

`secret.key` 不包含在数据库备份中。这样即使备份文件被复制走，其中的 Key 和密码仍是密文。

代价是用备份恢复到新设备时，需要把 `secret.key` 一起复制过去，或者重新填写这些配置。远程文件夹在没有原来的 `secret.key` 时显示离线，重新填写凭据后恢复，见[远程文件夹](./remote-folders#offline)。

这项加密只能防止数据库单独泄露，无法应对整台服务器被攻破的情况。

## 登录 {#login}

### 限流和锁定 {#login-limit}

同一个用户名 15 分钟内失败 5 次后，每次尝试要等的时间逐次加倍；失败 10 次锁定 15 分钟，并给这个帐号发一条通知。同一个 IP 失败 20 次也会暂停。

被锁定后可以等 15 分钟，或由所有者在成员页解除，或在服务器上运行 [`keepbay user:unlock`](./cli#user-unlock)。

### 会话 {#session}

会话在 30 天没有活动后失效，持续使用时一直有效。

Cookie 带 `HttpOnly`、`SameSite=Lax`，经 HTTPS 访问时加 `Secure`。修改密码后，其他设备上的登录失效。

### 两步验证 {#two-factor}

标准 TOTP（6 位、30 秒），用过的验证码不能再用。开启时给 10 个恢复码，每个只能用一次。

输完密码后 5 分钟内要完成第二步，最多试 5 次，失败同样计入限流。

### 通行密钥 {#passkey}

要求在设备上验证身份（指纹、面容或 PIN），可以不输用户名直接登录。对域名和 HTTPS 的要求见[外网访问](./remote-access#passkey)。

### 外部帐号登录 {#oidc}

始终使用 PKCE。OIDC 提供方（Authentik、Keycloak、Google、Microsoft 等）还会校验 ID Token 的签名、签发方、受众和有效期。GitHub 用的是 OAuth2，没有 ID Token，按 GitHub 的用户 ID 识别用户。

Keepbay 按身份提供方和其中的用户 ID 识别用户，不按邮箱自动关联已有帐号，否则他人在身份提供方修改邮箱后就能登录。

没有对应帐号时默认拒绝。所有者可以开启自动建号并限定邮箱或域名，自动建的帐号固定是成员。

外部帐号永远不能变成所有者，所有者也必须保留密码登录。这样在更换手机或身份提供方出现故障时，仍可以用密码登录。

### 敏感操作 {#reauth}

修改密码、开关两步验证、管理登录方式、在网页上更新程序，都要先确认一次身份。

确认的方式是输入密码，或者 5 分钟内用外部帐号重新验证过（GitHub 不支持重新验证）。

### 跨站请求 {#csrf}

所有修改类请求都要带一个自定义请求头，并核对 `Origin` 与站点自己的地址一致，不一致时拒绝请求，提示"请求来源不正确"。

经反向代理访问时出现这个提示，通常是因为没有设置可信代理，见[外网访问](./remote-access#trusted-proxies)。

### 首次设置 {#setup-token}

设置向导要输入启动时生成的一次性令牌，防止同一网络中的人抢先创建所有者，见[首次设置](./setup#token)。

## 文件访问 {#file-access}

所有对您文件的读写都经过同一个模块，它从文件夹根目录逐级打开，**不跟随任何符号链接**。

符号链接在界面上显示为链接，能看到它指向哪里，但不能通过它打开或进入。这样无论链接指向文件夹外部，还是指向成员无权访问的位置，都无法借此绕过限制。

以只读方式添加的文件夹在最底层拒绝所有写入，即使上层代码有错误，也无法写入。

成员只能访问所有者授权的文件夹（只读或读写）。对看不到的文件，接口一律按"不存在"返回，无法通过错误信息的差异来探测。

后台任务、撤销、恢复执行时会重新检查权限。

成员的三个开关默认都关闭，因为它们都会让数据离开这台设备：创建分享链接、使用云端 AI、离线下载。

## 处理不可信文件 {#sandbox}

照片解码库是用 C 写的，一张精心构造的图片就可能使它出错，进而被利用。所以 Keepbay 把 JPEG、PNG、RAW 等图片的解码放在一个受限的子进程里。

主进程打开文件后，只把只读的文件描述符交给它。子进程加载 seccomp 过滤器后，不能打开任何文件、不能联网、不能执行其他程序、不能写文件；内核 7.0 及以上再叠加一层 Landlock。

即使解码器被攻破，它也无法读取数据库和密钥，也无法向外发送任何数据。

视频和 HEIC 照片交给系统中的 ffmpeg 处理。ffmpeg 启动时需要加载自己的动态库，无法禁止它打开文件，因此对它的限制较宽：只能以只读方式打开文件，不能写文件、不能联网、不能创建新的进程，也不叠加 Landlock。细节见[技术架构](./architecture#sandbox)。

内核不支持 seccomp 时（部分 NAS），Keepbay 默认不在没有隔离的情况下解码照片和视频，也就不生成缩略图。

浏览器能直接显示的图片、能直接播放的视频仍然可以预览，文件也可以正常浏览和下载。

内核无法更换时，所有者可以在「系统设置 › 媒体处理」的"不支持系统调用过滤时"一节，打开「照样处理照片和视频」。打开时需要确认，之前跳过的照片和视频会重新处理。

打开后，解码仍在与主进程分开的子进程中进行，有内存和时间上限，但不再受系统调用过滤的限制。恶意文件可能利用解码器的漏洞，读取这台设备上的其他文件或联网。建议只在文件来源可信时打开。

关闭后恢复默认，新的照片和视频不再处理，已经生成的缩略图和预览图保留。

预览同样有防护措施：

- 文件原样返回时带 `Content-Security-Policy: sandbox`，即使被直接打开也不能执行脚本、不能向外部网站发请求（否则 SVG 文件可以借此获知是谁在什么时间打开了它）
- Word 文档、网页在不允许脚本的沙箱 iframe 中显示
- 下载一律以附件方式返回

## 分享链接 {#share}

- 链接中的令牌是随机 96 位，数据库存的是哈希，另有一份用 `secret.key` 加密的副本，用来在管理页中再次显示链接
- 可以设置密码、有效期（最长 10 年）、下载次数上限和下载限速
- 按 IP 和链接限流；尝试不存在的令牌、输错密码时，响应会逐次变慢
- 访客打开、下载都记在访问记录中；同一访客 30 分钟内重复打开只记一次，12 小时内重复下载同一个文件也只记一次（也只算一次下载次数）
- 分享带拍摄地点的照片时会提醒您：下载原图的人能看到地点
- 加水印的链接（专业版）在服务端生成水印图，访客无法获取原图

## 离线下载 {#offline-download}

离线下载会按用户提供的网址访问外网，主要风险是被用来访问内网，比如路由器的管理页、云服务器的元数据地址。

Keepbay 在建立连接时检查实际连接的 IP，只允许公网地址，通过跳转或 DNS 重绑定都无法绕过。BT 下载同样过滤内网地址，默认不做种。

Tailscale 的地址段（100.64.0.0/10）也在拒绝之列，离线下载无法连接您 Tailscale 网络中的设备。

## 诊断信息 {#diagnostics}

遇到问题需要求助时，可以在「系统设置 › 维护」中导出诊断信息：版本和系统、依赖检测、数据库检查、文件夹和任务队列的统计、最近的日志。导出前可以在页面上预览全部内容。

「隐藏路径、文件名和网址」默认打开，会把它们换成 `[路径1]` 这样的占位。

无论是否打开这个选项，`secret.key`、密码、会话、API Key、授权证书和您的文件内容都不会出现在诊断信息中，日志中的令牌和密码也会被清除。
