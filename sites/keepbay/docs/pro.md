# 专业版 {#pro}

免费版是一个完整的私有网盘：文件管理、预览、搜索、标签、分享、离线下载都能用，不限文件夹和文件数量。

专业版在此基础上加上 AI 整理和搜索，用户数不限。两者的功能对比见[介绍](./introduce#features)。

::: warning 内测阶段
Keepbay 目前处于内测阶段，专业版将在 1.0.0 正式版发布时开始销售，价格以届时的购买页为准。
:::

## 永久使用，含 1 年更新 {#license-model}

买了专业版，已经装的版本永久可以用，不会到期，不用每个月付钱。

价格中包含 1 年的更新服务。这 1 年里发布的新版本，新功能、新的本地模型和格式支持、改进和问题修复，都可以免费更新。

1 年后，您装的版本照常使用，专业版的功能照常可用。之后发布的新功能版本，续费一年更新后才能装。

安全修复始终免费。更新服务到期时您用的是 1.3，那么之后的 1.3.1、1.3.2 都能装。

我们没有做订阅制。资料放在 Keepbay 里，不续费就停功能，会让人不安；存储和 AI 默认也都在您自己的设备上，我们没有按月收费的理由。

另一方面，AI 部分需要持续维护，买一次送终身更新，我们做不下去。所以选了"永久使用 + 按年更新"。

## 续费 {#renew}

续费随时都可以，续了就能更新到最新版本。

更新服务还没到期时续费，从原来的截止日往后顺延一年，提前续不吃亏。已经到期的，从续费当天算起一年。中间断了一段时间再续，价格一样。

在授权中心网站续费后，到 Keepbay 的「系统设置 › 授权」中点「立即续期」，马上就能用上，不用等自动续期。

## 自己装了截止之后的版本 {#uncovered}

在网页上更新时，Keepbay 只会装更新服务期内的版本，期外的版本标为"续费后可以更新"。

自己手动装了更新服务截止之后发布的版本时，专业版的功能会暂停，授权页显示"专业版 · 已暂停"。文件和已有的数据都保留。

续费更新服务后点「立即续期」，或者换回截止日之前发布的版本，就恢复了。

换回旧版本要注意：已经被新版本升级过数据库的，旧版本打不开，要先用升级前的备份恢复，备份之后的改动会丢失，见[升级](./upgrade#database)。

暂停期间，专业版的功能和免费版一样不可用，用户超过 2 个时，多出来的成员也会暂停登录，见[成员和权限](./members#user-limit)。但这不算降为免费版，Keepbay 只通知一次"这个版本需要续费更新服务"。

## 试用 {#trial}

专业版可以免费试用 3 天，全部功能都能用。

在授权中心网站登录后领取试用授权码，再到 Keepbay 中照常激活。Keepbay 里没有"开始试用"的按钮，免费版的界面中不显示付费相关的内容。

试用从激活时算起，领了以后晚几天再装也不浪费。每个帐号、每台设备都只能试用一次。

资料多的话，3 天可能处理不完全部文件。试用时建议先添加一部分文件夹，看看效果。

试用期间买了正式授权，输入授权码就接上了，设置和数据都不变。试用结束没有购买的，降为免费版，文件和数据都保留。

## 激活 {#activate}

在「系统设置 › 授权」中输入购买后收到的授权码，点「解锁专业版」，联网取得这台设备的证书。

激活时只发送三样东西到授权中心 `huohuastudio.com`：授权码、这台设备的安装 ID、产品标识 `keepbay`。

激活后，证书保存在数据目录中，每次启动在本地验证，不需要联网。

安装 ID 是首次启动时生成的随机 UUID，不含任何硬件信息。它只用来让授权中心知道"这是同一台设备"。

## 离线激活 {#offline-activate}

不能联网的设备，或者联网激活失败时，可以离线激活：

1. 在授权页「离线激活」一节，复制这台设备的安装 ID
2. 在能上网的设备上打开授权中心网站，用授权码和安装 ID 取得证书
3. 回到授权页，粘贴证书的全部内容，或者「从文件读取」，点「导入证书」

续费后也可以用同样的方式手动导入新证书。

## 自动续期 {#auto-renew}

「到期前自动续期」默认打开。永久授权在更新服务截止日的前后 7 天内，每天最多联网一次，取回续费后的新证书。发送的内容和联网激活一样。

还没续费的话，什么都不会变，下次再试。

不想让 Keepbay 联网的，可以关闭自动续期，续费后点「立即续期」或手动导入证书。

## 设备 {#devices}

每个授权最多激活 3 台设备。

换设备时，先在旧设备的授权页点「在本机停用专业版」，再到授权中心网站上解绑旧设备，然后在新设备上激活。

本机停用只删除这台设备上的证书。设备名额要在授权中心网站上解绑后才会释放。

旧设备已经坏了、没法停用的，直接在授权中心网站上解绑。

重装系统、全新安装 Keepbay 会生成新的安装 ID，要重新激活一次，会占用一个名额。把整个数据目录原样搬过来的，安装 ID 不变，不用重新激活。

## 降为免费版后 {#downgrade}

在本机停用专业版、试用结束时，Keepbay 降为免费版：

- 您的文件不受任何影响
- 已有的标签、整理结果、提醒都保留，可以查看
- AI 搜索、AI 桌面、自动整理、AI 标签等专业版功能停止工作
- 已经确认的重要日期提醒照常发送。护照快过期了，不会因为没续费就不提醒
- 已经加了水印的分享链接照常加水印
- 用户超过 2 个时，多出来的成员暂停登录，见[成员和权限](./members#user-limit)

重新激活后，全部直接恢复，不用重新处理文件。

## 我们的承诺 {#promises}

已经免费的功能，以后不会改成收费。

两步验证、通行密钥、外部帐号登录这些安全功能，永远免费。

免费版中不显示"升级解锁"之类的按钮和提示。功能对比只放在授权页，想看的时候去看。
