# 专业版 {#pro}

免费版是一个完整的私有网盘：文件管理、预览、照片时间线和地图、搜索、标签、分享、离线下载都可以使用，不限文件夹和文件数量。

专业版在此基础上加上 AI 整理和搜索、[认识的人和宠物](./people)、[远程文件夹](./remote-folders)，用户数不限。两者的功能对比见[介绍](./introduce#features)。

::: warning 内测阶段
Keepbay 目前处于内测阶段，专业版将在 1.0.0 正式版发布时开始销售，价格以届时的购买页为准。
:::

## 免费试用 {#trial}

新安装的 Keepbay 可以免费试用专业版 7 天，包含全部专业版功能，从开启时起算。

设置向导的最后一步默认勾选「开启 7 天专业版试用（会连接授权中心）」，完成设置后自动开启。不需要注册帐号。不想试用时取消勾选即可；不能联网时自动跳过，不影响完成设置。设置时没有开启的，可以之后在「系统设置 › 授权」中开启。

资料较多时，AI 在 7 天内可能处理不完。建议试用时先添加一部分文件夹，购买后再添加其余的。

每台设备只能试用一次，同一个网络 180 天内最多试用 2 次。删除数据目录重新安装后不能再次试用。是否可以试用由授权中心判断，不能试用时授权页会说明原因，Keepbay 按免费版运行。开启试用时发送的内容见[隐私与安全](./privacy#outbound)。

试用期间输入购买的授权码，即可直接转为正式的专业版，已有的设置和数据都不变。试用结束前 1 天会提醒一次。试用没有宽限期，结束后降为免费版，文件和已有的数据都保留，见[降为免费版后](#downgrade)。

试用按本机时间判断是否结束。系统时间早于证书的签发时间，或被往回调过 1 天以上时，专业版的功能会暂停，授权页显示"系统时间不正确"，时间恢复后自动恢复。NAS 开机后还没有同步网络时间时也可能出现这种情况，同步后即恢复。

## 永久使用，含 1 年更新 {#license-model}

购买专业版后，已安装的版本可以永久使用，不会到期，也不需要按月付费。

价格中包含 1 年的更新服务。这 1 年里发布的新版本，新功能、新的本地模型和格式支持、改进和问题修复，都可以免费更新。

1 年后，您已安装的版本照常使用，专业版的功能照常可用。之后发布的新功能版本，需要续费一年更新后才能安装。

安全修复始终免费。更新服务到期时您用的是 1.3，那么之后的 1.3.1、1.3.2 都可以安装。

AI 部分需要持续维护，一次购买、终身更新的模式难以长期维持，所以我们采用"永久使用 + 按年更新"的方式。

## 续费 {#renew}

可以随时续费，续费后即可更新到最新版本。

更新服务还没到期时续费，从原来的截止日往后顺延一年，提前续费不会损失剩余的时间。已经到期的，从续费当天算起一年。中断一段时间后再续费，价格不变。

在授权中心网站续费后，到 Keepbay 的「系统设置 › 授权」中点「立即续期」，即可立即生效，不需要等待自动续期。

## 安装了更新服务期之后的版本 {#uncovered}

在网页上更新时，Keepbay 只会安装更新服务期内的版本，期外的版本标为"续费后可以更新"。

如果手动安装了更新服务截止之后发布的版本，专业版的功能会暂停，授权页显示"专业版 · 已暂停"。文件和已有的数据都保留。

续费更新服务后点「立即续期」，或者换回截止日之前发布的版本，即可恢复。

换回旧版本时请注意：已经被新版本升级过数据库的，旧版本无法打开，需要先用升级前的备份恢复，备份之后的改动会丢失，见[升级](./upgrade#database)。

暂停期间，专业版的功能和免费版一样不可用，用户超过 2 个时，超出的成员也会暂停登录，见[成员和权限](./members#user-limit)。但这不算降为免费版，Keepbay 只通知一次"这个版本需要续费更新服务"。

## 激活 {#activate}

在「系统设置 › 授权」中输入购买后收到的授权码，点「解锁专业版」，联网取得这台设备的证书。

激活时只向授权中心 `huohuastudio.com` 发送以下信息：授权码、这台设备的设备 ID 和安装 ID、机器指纹的哈希值、产品标识 `keepbay`。

激活后，证书保存在数据目录中，每次启动在本地验证，不需要联网。

安装 ID 是首次启动时生成的随机 UUID。设备 ID 由安装 ID 和机器指纹得出，证书绑定的是设备 ID，授权中心按它计算设备数。

机器指纹是这台机器几项信息（machine-id、物理网卡、数据目录所在的文件系统等）的哈希值，以安装 ID 为盐。Keepbay 只发送哈希值，不发送硬件信息的原文；同一台机器上的两次安装，指纹也不相同。

激活后，授权页和关于页显示"授权给"：授权中心帐号的名称和打码的联系方式，如"张三（z***@example.com）"。较早签发的证书没有这一项，不显示。

## 离线激活 {#offline-activate}

不能联网的设备，或者联网激活失败时，可以离线激活：

1. 在授权页「离线激活」一节，复制这台设备的设备 ID
2. 在能上网的设备上打开授权中心网站，用授权码和设备 ID 取得证书
3. 回到授权页，粘贴证书的全部内容，或者「从文件读取」，点「导入证书」

续费后也可以用同样的方式手动导入新证书。

## 自动续期 {#auto-renew}

「到期前自动续期」默认打开。永久授权在更新服务截止日的前后 7 天内，每天最多联网一次，取回续费后的新证书。发送的内容和联网激活一样。

如果尚未续费，授权状态不变，下次再尝试。

如果不希望 Keepbay 为续期联网，可以关闭自动续期，续费后点「立即续期」或手动导入证书。

## 设备 {#devices}

每个授权包含 3 个设备名额，按设备 ID 计算。名额用完后，可以在授权中心网站用积分添加。

在同一台机器上升级 Keepbay、重启、重建 Docker 容器，设备 ID 不变，不需要重新激活。

### 迁移后自动重新激活 {#rebind}

把数据目录复制或迁移到另一台机器后，设备 ID 会变。

激活时能读到 3 项及以上机器信息的，之后只变了其中一项仍算同一台设备，如更换网卡、重装系统，或把数据目录挪到另一块磁盘。激活时信息不足 3 项的（如 Docker 容器中默认只有数据目录一项），把数据挪到另一块磁盘、从备份恢复到新建的目录，也会被当作新设备。

设备 ID 变了以后，Keepbay 启动时自动用证书中的授权码联网重新激活，占用一个设备名额，通常几秒内完成。

重新激活不受「到期前自动续期」开关的影响。连不上授权中心时，14 天内照常使用专业版，授权页显示"专业版 · 等待重新激活"。这期间也可以离线导入证书，授权页上的设备 ID 已经是新的。14 天内没能重新激活的，按免费版运行，联网后自动恢复。

授权中心拒绝重新激活时（设备数已满、授权已吊销等），Keepbay 立即按免费版运行，文件和已有的数据都保留。之后每天自动重试一次；在网站上换绑后，也可以点「重新激活」立即恢复，见[换设备](#transfer)。

全新安装 Keepbay 会生成新的安装 ID，设备 ID 随之改变，需要输入授权码重新激活，同样占用一个名额。

### 换设备 {#transfer}

到授权中心网站，把不再使用的设备换绑为新设备的设备 ID（在新设备的「系统设置 › 授权」中查看）。换绑立即生效。授权自带的 3 个名额，第一次换绑免费，之后距上次换绑满 180 天的也免费，不满 180 天的扣积分；用积分添加的名额，每次换绑都扣积分。然后在新设备上输入授权码激活；数据迁移过去、重新激活被拒绝的，点「重新激活」。

网站上也可以删除设备，但名额要等这台设备绑定（或上次换绑）满 180 天后才空出。所以换设备时，建议用换绑。

旧设备上的「在本机停用专业版」只删除那台设备上的证书，不释放名额。旧设备已损坏、无法操作时，直接在网站上换绑即可。

## 降为免费版后 {#downgrade}

在本机停用专业版后，Keepbay 降为免费版：

- 您的文件不受任何影响
- 已有的标签、整理结果、提醒都保留，可以查看
- AI 搜索、AI 桌面、自动整理、AI 标签等专业版功能停止工作
- 认识的人和宠物停止识别，照片页不再显示「人物」；已有的人脸、名字和宠物保留
- 已经确认的重要日期提醒照常发送
- 已经加了水印的分享链接照常加水印
- 远程文件夹变为只读，可以浏览、搜索、下载，不能写入，也不能添加新的，见[远程文件夹](./remote-folders#license)
- 用户超过 2 个时，超出的成员暂停登录，见[成员和权限](./members#user-limit)

重新激活后，以上内容直接恢复，不需要重新处理文件。

## 我们的承诺 {#promises}

已经免费的功能，以后不会改成收费。

两步验证、通行密钥、外部帐号登录这些安全功能，始终免费。

免费版中不弹出"升级解锁"之类的提示，只有添加文件夹时选了"远程存储"，才会说明这是专业版的功能并给出解锁的入口。功能对比只在授权页中显示。
