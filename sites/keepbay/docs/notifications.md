# 通知 {#notifications}

Keepbay 可以通过 Bark 或邮件给您发通知：新版本、备份失败、磁盘或远程存储离线、重要日期提醒、帐号安全等。

每个人在「个人设置 › 通知」中设置自己的通知渠道，选择接收哪些通知。成员也可以设置，只接收与自己相关的通知。

## Bark {#bark}

[Bark](https://bark.day.app) 是 iPhone 上的推送 App，不需要注册帐号。

1. 在手机上安装 Bark，复制 App 中的推送地址
2. 在「个人设置 › 通知」中点「添加渠道」，选择 Bark
3. 把推送地址粘贴到「设备密钥」中，Keepbay 会自动取出密钥
4. 保存后点「发送测试通知」，确认手机能收到

使用自建 Bark 服务器的，填写「服务器地址」；不填时用 Bark 的官方服务器 `api.day.app`。

帐号安全类的通知，在手机开启专注模式时也会提醒。

## 邮件 {#email}

邮件要先由所有者设置发件服务器，全家共用。之后每个人添加自己的收件邮箱。

### 设置发件服务器 {#smtp}

所有者在「系统设置 › 网络」的「发件服务器」一节填写：

| 字段 | 说明 |
|---|---|
| 服务器 | 如 `smtp.qq.com` |
| 加密方式 | SSL（常用端口 465）、STARTTLS（常用端口 587）或不加密（端口 25，只用于本机的邮件服务器） |
| 端口 | 不填时按加密方式用常用端口 |
| 帐号、密码 | 邮箱的登录帐号和密码。很多邮箱要在网页版中开启 SMTP 服务，并用授权码代替登录密码 |
| 发件人 | 不填时用帐号作为发件人 |

密码加密保存，保存后不再显示。

填好后，在「测试收件地址」中填一个邮箱，点「发送测试邮件」。这会用当前填写的设置发送，无需先保存。

邮件不经过代理。服务器访问外网要经过代理的，请确保它能直接连接邮件服务器。

### 添加收件邮箱 {#email-channel}

在「个人设置 › 通知」中点「添加渠道」，选择邮件，填写收件地址，保存后点「发送测试通知」。

如果没有收到，请先检查垃圾邮件。

## 通知的种类 {#topics}

在「接收哪些通知」中，按种类打开或关闭。下表中"仅所有者"的种类，成员看不到。

| 通知 | 默认 | 内容 |
|---|---|---|
| 重要日期提醒 | 开 | 您确认过、关注了的证件、保修、保险、合同等到期日，按所选的提前天数在早上 9 点提醒（专业版） |
| 帐号安全 | 开 | 帐号被锁定、密码被修改、两步验证被关闭、添加了通行密钥、在新设备上登录 |
| 后台任务失败 | 开 | 自己发起的复制、移动、解压等没有完成 |
| 后台任务完成 | 关 | 自己发起的复制、移动、解压等全部完成，运行超过 1 分钟的才发 |
| 分享链接被访问 | 关 | 自己创建的分享链接被打开，每条链接每天最多一条 |
| 磁盘与文件夹 | 开 | 仅所有者。磁盘或远程存储离线超过 1 分钟、恢复在线，剩余空间不足（低于 5% 且少于 10 GB） |
| 专业版 | 开 | 仅所有者。有期限的授权到期前 30、7、1 天（开启自动续期时不发 7 天这一条），自动续期失败，宽限期结束降为免费版，安装的版本超出了更新服务期。更新服务到期本身不发通知，只在授权页和维护页提示 |
| AI 花费 | 开 | 仅所有者。本月云端 AI 花费达到上限的 80% 和 100%（专业版） |
| 收件箱 | 开 | 仅所有者。有新文件的整理建议待您处理，每天早上 9 点汇总一次（专业版） |
| 成员 | 开 | 仅所有者。有人用外部帐号登录，自动创建了新成员 |
| 数据库备份失败 | 开 | 仅所有者。自动备份没有成功，每天最多一条 |
| 新版本 | 开 | 仅所有者。自动检查发现了新版本，每个版本一条 |

"帐号安全"默认打开，建议保持开启。有人在新设备上登录您的帐号时，您会及时收到通知。

## 通知发到哪里 {#channels}

通知会发到您启用的每一个渠道。每人最多 10 个渠道，比如家里的 iPhone 和 iPad 各一个 Bark，再加一个邮箱。

渠道可以单独停用，无需删除。列表中显示每个渠道最近一次发送成功或失败的时间和原因。

没有启用任何渠道时，不会收到通知。

## 通知的内容 {#privacy}

通知会经过 Bark 的服务器或您的邮件服务商。通知中会有文件名、分享链接的标题、访问者的 IP 这类信息。

如果不希望这些信息经过第三方服务器，可以自建 Bark 服务器，或者使用自己的邮件服务器。
