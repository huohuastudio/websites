# 网络代理 {#proxy}

服务器需要经过代理访问外网时，在「系统设置 › 网络」中设置。保存后立即生效，无需重启。

## 代理方式 {#modes}

| 方式 | 说明 |
|---|---|
| 环境变量 | 默认。沿用启动 Keepbay 时的环境变量 `HTTPS_PROXY`、`HTTP_PROXY`、`NO_PROXY` |
| 不使用 | 所有连接都直连，环境变量中设置了代理也不使用 |
| 手动设置 | 在页面上填写代理服务器 |

手动设置时，可以选择 HTTP 代理或 SOCKS5 代理：

- HTTP 代理：访问 https 地址时用 CONNECT 方法
- SOCKS5 代理：域名由代理解析，服务器本地无法解析的域名也能访问

代理需要认证时，填写用户名和密码。密码加密保存，保存后不再显示。

修改代理服务器的地址后，原来的密码不会发送给新服务器，如有需要请重新填写。

## 环境变量 {#env}

使用"环境变量"方式时，代理需要设置在启动 Keepbay 的环境中。以系统服务运行的，在服务文件中添加：

```bash
sudo systemctl edit keepbay
```

```ini
[Service]
Environment=HTTPS_PROXY=http://192.168.1.2:7890
Environment=NO_PROXY=localhost,127.0.0.1
```

保存后重启服务：`sudo systemctl restart keepbay`。修改环境变量后需要重启服务才能生效。

网络页会显示当前读取到的环境变量中的代理，可以据此确认设置是否正确。

## 使用代理的功能 {#usage}

设置了代理以后，在同一页的「使用代理的功能」中选择哪些功能经过代理。每个功能一个开关，关掉的直连，改了立即生效。

| 功能 | 默认 | 包括 |
|---|---|---|
| 专业版 | 经过代理 | 联网激活和自动续期 |
| 检查更新 | 经过代理 | 检查新版本、下载安装包 |
| 外部帐号登录 | 经过代理 | 连接 Google、Microsoft、GitHub 等提供方 |
| 在线编辑 | 经过代理 | 读取编辑器支持的格式和验签用的公钥，见[在线编辑](./office) |
| 通知 | 经过代理 | Bark、企业微信、钉钉、飞书、Telegram 通知 |
| tracker 订阅 | 经过代理 | 取回离线下载中订阅的 tracker 列表，见[tracker 订阅](./offline-download#tracker-subs) |
| 本地模型 | 不经过 | 下载模型和运行环境、读取模型清单 |
| 离线下载 | 不经过 | 按链接下载文件和视频，BT 的 tracker 和 HTTP 下载源，安装和更新 yt-dlp、Deno |

本地模型和离线下载的流量较大，经过代理会消耗大量代理流量，因此默认直连。服务器要经过代理才能访问模型的下载源或视频网站时，打开对应的开关。

离线下载经过代理时，下载地址的域名经代理交给 Cloudflare 或 Google 的公共 DNS 解析，见[离线下载](./offline-download#security)。

专业版、本地模型两行只在专业版中显示。另有两类连接在别处设置：

- **AI 厂商**：每个厂商单独设置是否通过代理连接，见[AI 模型](./ai-models#providers)
- **远程文件夹**：每个远程文件夹在连接设置中单独选择「通过代理连接」，默认关闭，见[远程文件夹](./remote-folders#proxy)。S3 兼容存储用浏览器直连时，由浏览器直接连接存储，不经过这里的代理

以下连接始终不经过代理：

- 局域网地址
- 邮件通知。发件服务器需要能够直接连接
- BT 下载与其他用户之间的连接、DHT，以及 UDP tracker。这部分流量不经过代理，也不消耗代理的流量

Keepbay 何时联网、发送什么，见[隐私与安全](./privacy#outbound)。

### 从较早的版本升级 {#upgrade}

较早的版本中，设置了代理后所有功能都经过代理。升级后，离线下载、本地模型和远程文件夹改为直连，其他功能不变。

原来靠代理访问国外视频网站、模型下载源或境外远程存储的，升级后请打开对应的开关：离线下载、本地模型在「使用代理的功能」中打开；远程文件夹在「系统设置 › 存储」中点这个文件夹的「修改设置」，打开「通过代理连接」。

## 测试 {#test}

填好后点「测试」，Keepbay 会用页面上填写的设置连接 GitHub 和 Hugging Face，显示能否连接以及耗时（毫秒）。测试只读取响应头，不保存设置。

连接失败时会显示原因：

| 提示 | 原因 |
|---|---|
| 无法连接代理服务器 | 代理的地址或端口错误，或者代理没有运行 |
| 代理要求认证，或用户名、密码不正确 | 检查用户名和密码 |
| 代理无法连接到这个网站 | 代理本身无法连接目标网站 |
| 超时 | 网络太慢，或者被防火墙拦截 |
