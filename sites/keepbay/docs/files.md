# 浏览和预览 {#files}

Keepbay 的文件页参照电脑上的文件管理器设计：单击选中，双击打开，⌘ 和 Shift 多选，拖动移动，⌘Z 撤销。

熟悉访达或 Windows 资源管理器的用户，可以沿用原来的操作习惯。

下文的 ⌘ 在 Windows 和 Linux 上对应 Ctrl，⌥ 对应 Alt。两个平台不同的快捷键会分别列出。

## 列表和网格 {#views}

文件可以用列表或网格显示，⌘1 和 ⌘2 切换（Windows、Linux 为 Ctrl + 1、Ctrl + 2）。

列表的列是名称、类型、修改时间和大小。窗口窄的时候，先收起类型，再收起修改时间。

网格的图标大小可以用顶栏的滑块调整（窄屏时在「显示选项」中），也可以按 + 调大、按 - 调小。缩略图可以裁成方形，也可以保持原比例。

保持原比例时，图片按各自的宽高比排成等高的行，每行左右铺满，图片下方显示文件名。此时滑块调整的是行高。很窄或很宽的图片（宽高比超出 1:2 到 3:1）会居中裁切；文件夹和没有缩略图的文件按方形显示。

视图、排序和图标大小按文件夹分别保存。照片文件夹用网格，文档文件夹用列表，互不影响。

第一次打开的文件夹，沿用您上一次的设置；大部分内容是图片的，默认使用网格。这些设置保存在当前浏览器中，换一台电脑需要重新设置。

排序可以按名称、修改时间、拍摄时间、大小、类型，还可以把文件夹排在前面。名称按自然顺序排，`第2章` 在 `第10章` 前面；中文按拼音排。

拍摄时间取自照片和视频中记录的时间，按拍摄地的当地时间计算；没有记录的文件按修改时间排。选择拍摄时间时默认新的在前。列表视图按拍摄时间排序时，时间一列显示拍摄时间。

## 按日期分组 {#by-date}

网格保持原比例，并按拍摄时间或修改时间排序时，文件按天分组，每组上方显示日期和星期，例如「2026年11月14日 周六」。向下滚动时，当前组的日期停留在顶部。文件夹排在前面时，文件夹单独为一组。没有时间信息的项（如部分对象存储中的目录）归入「日期未知」。

内容超过一屏时，右侧显示日期条，代替滚动条。日期条上标出年份（只有一年的照片时标出月份），鼠标悬停显示该位置的日期，点击或按住拖动可以直接跳到对应的日期。手机和窄屏上，滚动时右侧边缘出现滑块，拖动滑块可以快速翻到任意日期。

方形网格、列表视图和其他排序方式不分组。分组只针对当前文件夹，不包括子文件夹中的文件。

一个文件夹里有十万个文件也能正常滚动。列表只渲染看得到的部分，全选时也无需等待所有项加载完成。

## 选择 {#select}

鼠标操作与电脑上的文件管理器一致：

- 单击选中一项，⌘ 单击加选或取消
- Shift 单击选中一段范围
- 从空白处拖动，框选
- 在选中的多项中任意一项上按住拖动，拖走的是全部选中项

也可以使用键盘：方向键移动，Shift + 方向键扩展选区，⌘A 全选，Esc 取消选择。

直接输入文字，会跳到名称匹配的项。支持拼音首字母，输入 `ht` 就能跳到"合同"。

手机和平板上，点顶栏的「选择」进入多选。

## 打开和快速查看 {#open}

双击或按 Enter，用默认方式打开文件。

需要快速查看时，选中文件后按空格。用方向键查看上一个、下一个，再按空格或 Esc 关闭。选中了多个文件时，只在选中的文件之间切换。

查看图片时，可以在顶栏「更多」中选「幻灯片播放」，再选每张停留的时间（3、5 或 10 秒）。程序按文件夹当前的排序依次播放其中的图片，跳过其他文件，播放到最后一张后从头继续。播放时全屏显示，按任意键或点击即停止。文件夹中至少有两张图片时才有这一项。

右键菜单的「打开方式 ›」列出能打开这个文件的所有方式。在「选择其他方式…」中，可以勾选"始终使用此方式打开"。

在「个人设置 › 打开方式」中，可以按文件种类或扩展名设置默认的打开方式。设为「下载」的，双击直接下载。这些设置每个人各自保存。

## 支持预览的格式 {#formats}

预览都在浏览器里完成，服务器上无需另外安装 Office 或转换程序。

| 类型 | 说明 |
|---|---|
| 图片 | JPEG、PNG、GIF、WebP、AVIF、BMP、SVG 直接显示；HEIC、TIFF 和相机 RAW（索尼 ARW、尼康 NEF、佳能 CR2 和 CR3、富士 RAF、松下 RW2、奥林巴斯 ORF、DNG 等）由服务器转成预览图 |
| 视频 | MP4、MOV、WebM 等浏览器能直接播放的格式。服务器不转码，MKV、AVI 这类请下载后用播放器打开 |
| 音频 | MP3、AAC、FLAC、WAV、OGG、Opus 等，能否播放取决于浏览器 |
| PDF | 只加载正在查看的页面，几百 MB 的文件也无需完整下载 |
| 文本和代码 | 带语法高亮，Markdown 按排版显示。超过约 26 万个字符或 1 万行的，只显示纯文本；超过 5 MB 的，只显示开头部分 |
| Word | 只支持 .docx，不支持旧版 .doc |
| 表格 | .xlsx、.xls、.ods、CSV、TSV |
| 演示文稿 | 只支持 .pptx，显示其中的文字和图片，不还原动画和版式 |

HEIC 照片和视频缩略图要用系统中的 ffmpeg，见[常见问题](./faq#ffmpeg)。

压缩包不能预览内容，可以右键「解压到这里」或「解压到收件箱」。支持 zip、tar、tar.gz、tar.bz2；不支持 rar、7z，也不支持加了密码的压缩包。

## 信息面板 {#info}

⌘I（Windows、Linux 为 Alt + Enter）或右键「详情」，打开右侧的信息面板。

面板中有类型、大小、修改时间、尺寸、时长、标签。选中多项时，显示合计大小。

照片和视频还会显示拍摄信息：拍摄时间、相机和镜头、光圈、快门、ISO、拍摄地点。

拍摄地点是用程序自带的城市数据离线查询得到的，坐标不会发给任何地图服务。点「在地图中打开」才会在新标签页打开 OpenStreetMap，打开前会先提示这会把坐标发给它。

拍摄时间按拍摄地当时的时间显示，不换算成您所在的时区。例如在东京晚上七点拍摄的照片，在其他时区查看时仍显示晚上七点。

## 编辑 {#edit}

文本文件和图片可以直接修改。在查看器顶栏点「编辑」，或者在右键「打开方式」中选文本编辑器、图片编辑器。

⌘S 保存，⌘⇧S 另存为副本。

保存时，原来的内容作为旧版本放进回收站。如需恢复修改前的内容，可以撤销，或者从回收站找回。

图片编辑只有旋转、翻转和裁剪，没有调色和滤镜：

- JPEG、PNG、WebP、TIFF 按原格式保存，保留拍摄信息
- HEIC 和相机 RAW 只能另存为 JPEG 副本
- 动图、多页图片、超过 1.2 亿像素的图片不能编辑

文本编辑器只能编辑 UTF-8 编码、5 MB 以内的文件。

## 新建、移动和复制 {#organize}

页头的「新建」菜单和右键空白处，可以新建文件夹（⌥⌘N，Windows、Linux 为 Ctrl + Alt + N），也可以新建文本、Markdown、CSV、JSON、HTML 等文件。

移动和复制有几种方式：

- 拖到文件夹、面包屑或侧栏上
- ⌘C 或 ⌘X，再 ⌘V
- 右键「移动到…」「复制到…」

这里的复制和粘贴只在 Keepbay 内部生效，不影响系统剪贴板里的文字。

拖动时，在同一个挂载的文件夹里默认是移动，拖到另一个挂载的文件夹默认是复制。按住 ⌥（Windows、Linux 为 Ctrl）可以切换。

卡片下方会写明是"移动 3 项到「文档」"还是"复制 3 项到「文档」"，松开鼠标前可以确认。

两个挂载的文件夹之间默认复制，是因为它们往往在不同的磁盘上。如果误把几百 GB 的照片移到另一块磁盘，移回来需要很长时间。

拖到一个文件夹上停留约一秒，文件夹会自动打开，可以逐级拖入深层的子文件夹。

手机上不能拖动。长按弹出菜单，用「移动到…」「复制到…」选择目标。

这些操作都可以用 ⌘Z 撤销，见[回收站和撤销](./trash#undo)。

## 只读和离线的文件夹 {#locked}

以下文件夹中的内容不能修改：

- 以只读方式添加的文件夹
- 专业版到期后的[远程文件夹](./remote-folders#license)
- 成员只获授权读取的文件夹，见[成员和权限](./members#folders)
- 离线的文件夹，包括嵌套添加在其他文件夹中、磁盘离线的文件夹，见[离线状态](./folders#offline)

在这些文件夹中，右键菜单的新建、改名、剪切、粘贴、移动到、移到回收站、立即删除、加水印、解压到这里显示为灰色，页头的「新建」「上传」按钮不可用，也不能把文件拖进来上传。

按对应的快捷键时，页面会提示"这个文件夹是只读的，不能修改"或"这个文件夹离线，暂时不能修改"。

只读的文件夹中，复制、复制到、下载、详情照常可用。标签保存在 Keepbay 的数据库中，所有者可以照常添加，成员不能。

离线的文件夹中，原文件在恢复在线之前无法读取，不能打开、下载和复制。已经生成的缩略图和预览图仍可查看。

文件夹离线、恢复在线，或者改为只读、恢复读写时，打开着的页面会自动更新。

## 隐藏文件和链接 {#hidden}

名称以点开头的文件和文件夹默认不显示，⇧⌘.（Windows、Linux 为 Ctrl + Shift + .）切换。

这个设置对所有文件夹生效，保存在当前浏览器中。不显示时，搜索结果中也不会出现它们。

符号链接显示为"链接"，在信息面板中可以看到它指向哪里。但不能通过它打开文件或进入文件夹，下载和分享时也会跳过。

如需访问链接指向的位置，所有者可以把那个位置单独添加为文件夹。原因见[隐私与安全](./privacy#file-access)。

## 快捷键 {#shortcuts}

按 ⌘/ 或 ? 可以随时查看快捷键列表。

| 功能 | macOS | Windows、Linux |
|---|---|---|
| 打开 | Enter、⌘↓ | Enter |
| 上一级 | ⌘↑ | Alt + ↑ |
| 后退、前进 | ⌘[、⌘] | Alt + ←、Alt + → |
| 直接输入路径 | ⌥⌘G | Ctrl + Alt + G |
| 快速查看 | 空格 | 空格 |
| 改名 | F2 | F2 |
| 移到回收站 | ⌘⌫ | Delete |
| 立即删除 | ⌥⌘⌫ | Shift + Delete |
| 撤销、重做 | ⌘Z、⇧⌘Z | Ctrl + Z、Ctrl + Y |
| 复制、剪切、粘贴 | ⌘C、⌘X、⌘V | Ctrl + C、Ctrl + X、Ctrl + V |
| 新建文件夹 | ⌥⌘N | Ctrl + Alt + N |
| 信息面板 | ⌘I | Alt + Enter |
| 列表、网格 | ⌘1、⌘2 | Ctrl + 1、Ctrl + 2 |
| 网格中调大、调小图标 | +、- | +、- |
| 显示隐藏文件 | ⇧⌘. | Ctrl + Shift + . |
| 在当前文件夹中搜索 | ⌘F 或 / | Ctrl + F 或 / |
| 搜索文件和命令 | ⌘K | Ctrl + K |
| 快捷键列表 | ⌘/ 或 ? | Ctrl + / 或 ? |

新建文件夹没有使用访达的 ⇧⌘N，因为浏览器用它打开无痕窗口，网页无法拦截。

空格、F2、Delete、/、?、+、- 这类不带 ⌘、Ctrl、Alt 的单键快捷键，打字时容易误触，可以在「个人设置 › 快捷键」中关闭。方向键、Enter、Esc 不受影响。
