# 浏览和预览 {#files}

Keepbay 的文件页参照电脑上的文件管理器设计：单击选中，双击打开，⌘ 和 Shift 多选，拖动移动，⌘Z 撤销。

熟悉访达或 Windows 资源管理器的用户，可以沿用原来的操作习惯。

下文的 ⌘ 在 Windows 和 Linux 上对应 Ctrl，⌥ 对应 Alt。两个平台不同的快捷键会分别列出。

## 列表和网格 {#views}

文件可以用列表或网格显示，⌘1 和 ⌘2 切换（Windows、Linux 为 Ctrl + 1、Ctrl + 2）。

列表的列是名称、类型、修改时间和大小。窗口窄的时候，先收起类型，再收起修改时间。

文件夹的大小是其中全部文件的总大小，包括各级子文件夹，见[文件夹大小](#folder-size)。

手机上顶栏不显示路径。点页面上方的文件夹名称，可以跳到上级任意一层；左上角的返回按钮回到上一级，旁边的菜单按钮打开侧栏。「新建」和「上传」合并在顶栏的「+」中。

网格的图标大小可以用顶栏的滑块调整（窄屏时在「显示选项」中），也可以按 + 调大、按 - 调小。缩略图可以裁成方形，也可以保持原比例。

保持原比例时，图片按各自的宽高比排成等高的行，每行左右铺满，图片下方显示文件名。此时滑块调整的是行高。很窄或很宽的图片（宽高比超出 1:2 到 3:1）会居中裁切；文件夹和没有缩略图的文件按方形显示。

视图、排序和图标大小按文件夹分别保存。照片文件夹用网格，文档文件夹用列表，互不影响。

第一次打开的文件夹，沿用您上一次的设置；大部分内容是图片的，默认使用网格。这些设置保存在当前浏览器中，换一台电脑需要重新设置。

排序可以按名称、修改时间、拍摄时间、大小、类型，还可以把文件夹排在前面。名称按自然顺序排，`第2章` 在 `第10章` 前面；中文按拼音排。按大小排序时，文件夹按总大小排，占用空间较多的文件夹排在一起。

拍摄时间取自照片和视频中记录的时间，按拍摄地的当地时间计算；没有记录的文件按修改时间排。选择拍摄时间时默认新的在前。列表视图按拍摄时间排序时，时间一列显示拍摄时间。

## 按日期分组 {#by-date}

网格保持原比例，并按拍摄时间或修改时间排序时，文件按天分组，每组上方显示日期和星期，例如「2026年11月14日 周六」。向下滚动时，当前组的日期停留在顶部。文件夹排在前面时，文件夹单独为一组。没有时间信息的项（如部分对象存储中的目录）归入「日期未知」。

内容超过一屏时，右侧显示日期条，代替滚动条。日期条上标出年份（只有一年的照片时标出月份），鼠标悬停显示该位置的日期，点击或按住拖动可以直接跳到对应的日期。手机和窄屏上，滚动时右侧边缘出现滑块，拖动滑块可以快速翻到任意日期。

方形网格、列表视图和其他排序方式不分组。分组只针对当前文件夹，不包括子文件夹中的文件。

一个文件夹里有十万个文件也能正常滚动。列表只渲染看得到的部分，全选时也无需等待所有项加载完成。

## 选择 {#select}

鼠标操作与电脑上的文件管理器一致：

- 单击选中一项，⌘ 单击加选或取消
- Shift 单击选中一段范围
- 从空白处拖动，框选
- 在选中的多项中任意一项上按住拖动，拖走的是全部选中项

也可以使用键盘：方向键移动，Shift + 方向键扩展选区，⌘A 全选，Esc 取消选择。

直接输入文字，会跳到名称匹配的项。支持拼音首字母，输入 `ht` 就能跳到"合同"。

手机和平板上，点顶栏的「选择」进入多选。

## 打开和快速查看 {#open}

双击或按 Enter，用默认方式打开文件。

需要快速查看时，选中文件后按空格。用方向键查看上一个、下一个，再按空格或 Esc 关闭。选中了多个文件时，只在选中的文件之间切换。

在快速查看中点「在查看器中打开」，进入完整的查看器。这样进入的查看器，右上角同一位置有「缩小为快速查看」按钮：点它关闭查看器，回到原来的文件夹、搜索结果或照片页，并打开当前文件的快速查看。在查看器中切换过文件的，打开的是切换后的文件。有未保存的修改、正在保存，或者正在用在线编辑器编辑时，没有这个按钮。按 Esc 仍是直接关闭查看器。

查看图片时，可以在顶栏「更多」中选「幻灯片播放」，再选每张停留的时间（3、5 或 10 秒）。程序按文件夹当前的排序依次播放其中的图片，跳过其他文件，播放到最后一张后从头继续。播放时全屏显示，按任意键或点击即停止。文件夹中至少有两张图片时才有这一项。

右键菜单的「打开方式 ›」列出能打开这个文件的所有方式。在「选择其他方式…」中，可以勾选"始终使用此方式打开"。

在「个人设置 › 打开方式」中，可以按文件种类或扩展名设置默认的打开方式。设为「下载」的，双击直接下载。这些设置每个人各自保存。

打开视频时默认自动播放、有声音。在「个人设置 › 打开方式」的「视频播放」中，可以关闭自动播放，或设为默认静音。打开音频时显示的画面在「音频播放」中设置，见[音频](#audio)。

## 收藏和最近 {#favorites}

侧栏「首页」下面有「最近」「收藏」「照片」三项。照片见[照片时间线](./photos)。

### 收藏 {#favorite}

文件和文件夹都可以收藏（添加到 Keepbay 的文件夹本身除外），有三种方式：

- 右键「收藏」
- 信息面板中点标题旁的星标
- 选中后按 ⌘D（Windows、Linux 为 Ctrl + D）

再操作一次即取消收藏。

侧栏「收藏」中按收藏时间列出。收藏是每个人自己的，家人看不到。

收藏的文件改名、移动、编辑保存后仍在收藏中。移到回收站、失去所在文件夹的权限后，不再显示。

### 最近 {#recent}

侧栏「最近」的页面上方，可以切换「最近打开」和「最近修改」。

**最近打开**列出您用查看器打开或下载过的文件，保留最近 200 个。记录保存在服务器上，换一台电脑、用手机登录看到的都一样。点「清除记录」可以清空，只清除记录，不删除文件。⌘K 中的"最近打开"也是这份记录。

**最近修改**列出您能看到的全部文件中最近改动过的，按改动的时间排列，文件夹不列入。每一行写明是谁改的：

- 通过 Keepbay 上传、编辑保存、复制的文件，写改动的人
- 在 NAS 的文件管理、终端或其他程序中直接改动的文件，写"在磁盘上变化"
- 解压、离线下载放进来的文件，也写"在磁盘上变化"
- [远程文件夹](./remote-folders)重新扫描后，存储返回的修改时间与写入时精度不同的，会变成"在磁盘上变化"，也不再出现在「只看我的」中
- 通过[收集链接](./share#collect)上传的文件，写建链接的人

打开「只看我的」，只列出自己改的文件。

两个页面的筛选、排序和右键菜单与搜索结果页相同。

## 支持预览的格式 {#formats}

预览都在浏览器里完成，服务器上无需另外安装 Office 或转换程序。

部署了 Office 编辑器时，Word、Excel、PowerPoint 等文档还可以在线编辑，见[在线编辑](./office)。

| 类型 | 说明 |
|---|---|
| 图片 | JPEG、PNG、GIF、WebP、AVIF、BMP、SVG 直接显示；HEIC、TIFF 和相机 RAW（索尼 ARW、尼康 NEF、佳能 CR2 和 CR3、富士 RAF、松下 RW2、奥林巴斯 ORF、DNG 等）由服务器转成预览图 |
| 视频 | MP4、MOV、WebM 等浏览器能直接播放的格式，以及 [TS 视频](#ts)。MKV、AVI 这类服务器不转码，请下载后用播放器打开。同名的字幕文件自动加载，见[视频字幕](#subtitles) |
| 音频 | MP3、AAC、FLAC、WAV、OGG、Opus 等，能否播放取决于浏览器 |
| PDF | 只加载正在查看的页面，几百 MB 的文件也无需完整下载 |
| 文本和代码 | 带语法高亮，Markdown 按排版显示，见[Markdown](#markdown)。超过约 26 万个字符或 1 万行的，只显示纯文本；超过 5 MB 的，只显示开头部分 |
| Word | 只支持 .docx，不支持旧版 .doc |
| 表格 | .xlsx、.xls、.ods、CSV、TSV |
| 演示文稿 | 只支持 .pptx，显示其中的文字和图片，不还原动画和版式 |
| 压缩包 | zip、tar、tar.gz、tar.bz2、7z、rar，不解压即可查看其中的文件，见[压缩包](#archive) |

HEIC 照片、视频缩略图和 TS 视频的在线播放要用系统中的 ffmpeg，见[常见问题](./faq#ffmpeg)。

### 压缩包 {#archive}

双击压缩包，在查看器中列出其中的文件和文件夹，以及各项的修改时间和大小。支持 zip、tar、tar.gz、tar.bz2、7z、rar。

- 点文件夹进入，点上方的位置回到上一级
- 点图片、文字文件直接预览，预览中也可以下载；其他文件点击后下载
- 能预览的图片是 JPEG、PNG、GIF、WebP、AVIF、BMP，最大 32 MiB；文字文件最大 5 MiB。HEIC、RAW、SVG 和超过大小的文件，请下载后查看
- 勾选几项后，点「解压选中的项到这里」或「解压选中的项到…」，只解出这几项
- 不勾选时，点「解压到这里」或「解压到…」，解出全部内容

勾选的项要在同一层。一次最多勾选 1000 项。

解压在后台进行，进度在侧栏的「更多 › 后台任务」中。也可以不打开压缩包，直接右键「解压到这里」或「解压到收件箱」。

以下压缩包不支持查看和解压，查看器中显示"不支持查看"和原因，整个压缩包仍可以下载：

- 加了密码的
- 分卷的
- 已损坏的，或者解压后过大、压缩比异常的

压缩包中的符号链接，以及名称不安全的项（如带 `../`，会写到压缩包之外），不列出，解压时也跳过。

很大的 tar.gz、tar.bz2 要从头解压才能列出全部内容，打开时需要等一会儿。预览其中靠后的一项也是如此。

能看到压缩包的成员，都能查看和下载其中的项。解压要对目标文件夹有修改权限。

压缩包在受限的子进程中读取，原因见[隐私与安全](./privacy#sandbox)。

### TS 视频 {#ts}

电视录制、摄像机拍摄的 TS 视频（.ts、.m2ts、.mts）浏览器不能直接播放，播放时由服务器用 ffmpeg 转换封装格式，视频不重新编码，进度条可以拖到任意位置。分享链接的访客页面也可以在线播放。

以下情况不能在线播放，可以下载后用其他播放器打开：

- 服务器上没有安装 ffmpeg
- 视频不是 8 位、4:2:0 的 H.264 编码，例如电视录制常见的 MPEG-2、HEVC，以及 10 位的 H.264
- 文件在[远程文件夹](./remote-folders)中
- 浏览器不支持这种播放方式

登录后的查看器中会说明以上原因，访客页面只提示无法预览并提供下载。码率极高、超出浏览器缓冲上限的视频也不能在线播放，此时提示的是格式或编码不支持。服务器同时最多转换 6 个视频，超过时提示稍后重试。

关键帧间隔超过 60 秒的视频，拖动后从目标位置之后的关键帧开始播放。连续录制超过约 26.5 小时的文件，拖动的位置可能不准。

### 视频字幕 {#subtitles}

播放视频时，Keepbay 自动加载同一文件夹中同名的字幕文件。支持 .srt、.vtt、.ass、.ssa 四种格式，例如 `电影.mp4` 配 `电影.srt`。

文件名中带语言标记的也能识别，例如 `电影.chs.srt`、`Movie.en.srt`。有多个字幕时，在播放器的字幕菜单中切换或关闭，每个视频最多列出 20 个。

- 有字幕时默认显示；有多个时优先显示中文
- 在播放器中切换或关闭字幕后，之后打开的视频沿用这次的选择
- 不需要字幕的，可以在「个人设置 › 打开方式」的「视频播放」中关闭「显示字幕」

字幕文件可以是 UTF-8、UTF-16 或 GBK 编码。ASS、SSA 字幕只显示文字，不显示样式和特效。

字幕按纯文字显示，其中的 HTML 和样式标记都会去掉，不会被当作网页内容执行。

以下情况不会加载字幕：

- 字幕在子文件夹中，例如 `Subs/`
- 字幕内嵌在视频文件中
- 单个字幕文件超过 8 MB
- 通过分享链接观看

### 音频 {#audio}

音频用网盘自带的播放器打开，背景是封面颜色模糊后的效果。播放器显示封面、标题、歌手和专辑，标题等信息取自音频文件中的标签，没有标签时用文件名。

- 播放完自动播放同一文件夹中的下一首，按文件夹当前的排序，跳过其他文件。从搜索结果、智能文件夹打开时，按打开时的列表续播
- 播放超过 3 秒后按「上一首」，回到这一首的开头
- 音量和静音状态保存在这台设备上
- 支持键盘的媒体键、手机锁屏界面和系统通知栏中的播放控制
- 在查看器中按空格播放或暂停
- 同一时间只有一个音频或视频出声：开始播放时，页面上其他正在出声的音频、视频自动暂停。静音的不受影响

右上角的两个按钮用来切换歌词和频谱，再按一次回到只显示封面和控件的画面。切换画面时播放不中断。手动切换的画面在之后打开的音频中继续使用，重新加载页面后恢复为设置中的画面。

**歌词**的来源有两种，两者都有时优先使用带时间的；都带时间或都不带时间时，使用 .lrc 文件：

- 同一文件夹中的同名 .lrc 文件，例如 `晴天.mp3` 配 `晴天.lrc`。支持 UTF-8、UTF-16 和 GBK 编码
- 音频文件内嵌的歌词，例如 MP3 的 USLT、SYLT 标签，FLAC、OGG 的 LYRICS 标签

带时间的歌词逐行滚动，当前行高亮，点某一行跳到该处播放；时间相同的第二行作为翻译显示在下面。不带时间的歌词整段显示。程序不联网查找歌词。

**频谱**根据正在播放的声音实时绘制，有环形和横向两种样式，在频谱下方切换，选择保存在这台设备上。频谱在浏览器中计算，服务器不参与。显示过频谱后，远程文件夹中的音频改为经服务器读取，不再由浏览器直接连接存储。

在「个人设置 › 打开方式」的「音频播放」中，可以设置打开音频时显示的画面：

| 选项 | 打开时显示 |
|---|---|
| 自动（默认） | 有带时间的歌词时显示歌词，否则显示频谱 |
| 歌词 | 歌词；没有歌词时显示添加歌词的方法 |
| 频谱 | 频谱 |

在外观设置中选择减少动态效果时，歌词直接跳到当前行，频谱不播放动画。分享链接的访客页面仍使用浏览器自带的播放控件。

## 实况照片 {#live}

Keepbay 识别两种实况照片（也叫动态照片）：

- Google、三星等安卓手机拍摄的，是在 JPEG 或 HEIC 照片中嵌入了几秒的视频，只有一个文件
- iPhone 拍摄的，是一张照片（HEIC 或 JPG）和一段同名的短视频（MOV），共两个文件，见[iPhone 实况照片的配对](#live-pair)

网格中，实况照片的缩略图左上角有实况标志。列表中，标志显示在名称后面。

在查看器中打开实况照片，左上角有「实况」按钮。鼠标悬停在按钮上或按住按钮时，播放视频；鼠标移开、也没有按住时，回到照片。播放时没有声音。

- 触屏上按住按钮播放
- 用键盘时，聚焦按钮后按住空格或 Enter
- 开了「减少动态效果」时，悬停不播放，只在按住时播放。这一项在「个人设置 › 外观」中设置，选「跟随系统」时按系统的设置

部分手机拍摄的视频是 HEVC 编码，有的浏览器无法播放。这时服务器用 ffmpeg 把视频转成 H.264 后播放，第一次播放要等约 1 秒，转换结果会缓存，之后直接使用。

服务器无法转换时，按钮显示为灰色，并说明原因，照片本身照常显示，处理方法见[常见问题](./faq#live-photo)。

转换后的视频长边最多 1280 像素、每秒最多 30 帧，只保留前 10 秒。HDR 视频转换后颜色会偏淡。

实况照片不能编辑，也不能批量加水印。否则保存后，安卓实况照片中的视频会丢失；iPhone 实况照片中，修改后的照片会与视频不一致。

访客打开分享链接时的显示见[访客的权限](./share#guest)，分享时加水印的处理见[分享时加水印](./share#share-watermark)。

### iPhone 实况照片的配对 {#live-pair}

同一文件夹中，名称相同（不含扩展名，不区分大小写）的照片和 MOV 视频，会自动配对为实况照片。视频要带画面（只有声音的不算），时长不超过 4 秒。

两个文件中都记录了苹果的内容编号时，编号一致才配对。只有一个文件记录了编号，或都没有记录时，只按名称配对。

配对的视频默认不在文件夹中单独显示。需要看到它时，在顶栏「显示选项」中打开「显示实况照片的视频」。这个设置对所有文件夹生效，保存在当前浏览器中。搜索结果中照常显示这些视频。

配对只影响显示。移动、改名、删除、分享、下载时，照片和视频仍是两个文件，分别处理。例如只把照片移到别的文件夹，视频留在原处，两者不再配对。

## 信息面板 {#info}

⌘I（Windows、Linux 为 Alt + Enter）或右键「详情」，打开右侧的信息面板。

面板中有类型、大小、修改时间、尺寸、时长、标签。选中多项时，显示合计大小，选中的文件夹按总大小计入。名称右侧的链接按钮用来[复制链接](#copy-link)，星标用来[收藏](#favorite)。

只选中一项时，面板中有「备注」一节，见[备注](#notes)。文件有旧版本时，面板中有「历史版本」一节，见[历史版本](./trash#versions)。

照片和视频还会显示拍摄信息：拍摄时间、相机和镜头、光圈、快门、ISO、拍摄地点。

拍摄地点是用程序自带的城市数据离线查询得到的，坐标不会发给任何地图服务。点「在地图中打开」才会在新标签页打开 OpenStreetMap，打开前会先提示这会把坐标发给它。

拍摄时间按拍摄地当时的时间显示，不换算成您所在的时区。例如在东京晚上七点拍摄的照片，在其他时区查看时仍显示晚上七点。

### 文件夹大小 {#folder-size}

选中一个文件夹，或者没有选中任何项时，面板显示文件夹的大小，以及"包含 N 个文件、M 个文件夹"。数字包括各级子文件夹。

面板下方的「空间分析」按钮，用来查看这个文件夹中哪些子文件夹、哪类文件占用空间较多，见[空间分析](./space)。

大小按 Keepbay 的索引统计，不重新读取磁盘，所以大文件夹也能立即显示。统计口径如下：

- 隐藏文件计入
- 回收站中的、被[忽略规则](./folders#ignore)排除的不计入
- 硬链接、稀疏文件、文件系统的块大小和透明压缩都不考虑，与磁盘上实际占用的空间可能不同

文件变化后，几秒内更新。刚添加较大的文件夹时，数字要等扫描完成后才完整。磁盘离线时，照常显示索引中的数字。

成员看到的是他能打开的文件夹的完整大小。授权对子文件夹同样有效，所以这个数字不包含他看不到的内容。

搜索结果、收藏和最近中，文件夹不显示大小，多选时的合计也只算文件。这些页面中的项可能互相包含，合计会重复计算。

### 备注 {#notes}

只选中一个文件或文件夹时，面板中标签的下方有「备注」一节，用来写一段说明，例如合同的签订背景、照片的拍摄经过。

没有备注时点「添加备注」，有备注时点标题右侧的「编辑」。⌘↩（Windows、Linux 为 Ctrl + Enter）保存，Esc 取消。

- 纯文本，最多 1000 字，保留换行
- 备注中的 http、https 网址可以点击，在新标签页中打开
- 备注下方写明最后修改的人和时间
- 删除备注时，进入编辑、清空内容后保存，在确认框中点「删除备注」。删除后不能恢复

备注是全家共用的。能看到这一项的成员都能看到备注，对它有修改权限的成员可以修改。添加到 Keepbay 的文件夹本身不能写备注，其中的文件和子文件夹都可以。

备注保存在 Keepbay 的数据库中，不改动文件本身。因此以只读方式添加的文件夹、离线的文件夹中，也可以写备注。

两个人同时编辑一条备注时，后保存的人会看到提示，说明刚被谁修改过。再次保存会替换对方的内容。

文件改名、移动、编辑保存、恢复历史版本后，备注仍在。复制文件时不带备注。回收站中的项不显示备注。

备注中的文字可以搜索，见[搜索](./search#notes)。查看器的信息栏中同样可以查看和编辑备注。

## 编辑 {#edit}

文本文件和图片可以直接修改。在查看器顶栏点「编辑」，或者在右键「打开方式」中选文本编辑器、图片编辑器。

Office 文档的编辑要另行部署编辑器，见[在线编辑](./office)。

⌘S 保存，⌘⇧S 另存为副本。

保存时，原来的内容成为旧版本。如需恢复修改前的内容，可以撤销，或者在信息面板的「历史版本」中恢复，见[历史版本](./trash#versions)。

图片编辑只有旋转、翻转和裁剪，没有调色和滤镜：

- JPEG、PNG、WebP、TIFF 按原格式保存，保留拍摄信息
- HEIC 和相机 RAW 只能另存为 JPEG 副本
- 动图、多页图片、超过 1.2 亿像素的图片不能编辑
- [实况照片](#live)不能编辑

文本编辑器只能编辑 UTF-8 编码、5 MB 以内的文件。编辑 Markdown 时可以边写边看、粘贴图片，见[Markdown](#markdown)。

## Markdown {#markdown}

Keepbay 中的笔记就是文件夹中的 .md 文件，不另建笔记库。查看时按排版显示，编辑时可以边写边看、粘贴图片。

### 引用网盘中的图片和文件 {#markdown-refs}

文档中用相对路径写的图片和链接，按这篇 .md 所在的文件夹在网盘中查找：

| 写法 | 效果 |
|---|---|
| `![](images/a.png)`、`![](../照片/b.jpg)` | 直接显示网盘中的图片 |
| `[合同](合同.pdf)` | 在查看器中打开这个文件，关闭后回到文档 |
| `[照片](../照片)` | 进入这个文件夹 |
| `[安装](#安装)` | 跳到文中的标题 |

标题的锚点按 GitHub 的规则生成：英文字母改为小写，空格换成 `-`，去掉标点。

路径中可以有中文。有空格的写成 `%20`，或者用尖括号括起来，如 `![](<我的 图片.png>)`。否则不是有效的 Markdown 图片，按原文显示。

只显示您有权限查看的文件。没有权限和找不到时，显示同样的说明。成员只能引用被授权的文件夹之内的文件，两个平级的授权文件夹之间不能用 `../` 互相引用。路径不能越出添加的文件夹，也不经过符号链接。

图片显示的是长边最多 2048 像素的预览图；Keepbay 还没识别的图片显示原图。

外部网址的图片仍不自动加载，点击后在新标签页中打开。否则对方网站会知道您在查看这篇文档。

以下写法不支持：

- 以 `/` 开头的绝对路径
- Obsidian 的 `![[ ]]`、`[[笔记名]]`
- 大小写与实际名称不一致的路径。Linux 上它们是不同的文件

### 边写边看 {#markdown-preview}

编辑 Markdown 时，顶栏有「预览」开关。

宽屏上默认左右分栏，左边编辑，右边实时预览。编辑器滚动时，预览跟着滚到对应的位置。关闭开关收起预览。

窄屏上默认只有编辑器，开关在编辑和预览之间切换。切到预览时，预览定位到编辑器当前对应的位置。

停止输入约 0.2 秒后，预览更新。只显示纯文本的大文件（见[支持预览的格式](#formats)）没有这个开关。

### 粘贴和拖入图片 {#markdown-images}

编辑 Markdown 时，可以直接粘贴或拖入图片。图片存到这篇笔记所在文件夹下的 `assets` 文件夹中，并在光标处插入相对路径的链接，如 `![image-20261119-100533](assets/image-20261119-100533.png)`。

- `assets` 文件夹不存在时自动新建；已有名为 `assets` 的文件时说明原因，不插入
- 与已有的图片重名时，保留两者
- 截图没有文件名，按本机时间命名，如 `image-20261119-100533.png`；拖入的文件保留原名
- 剪贴板中同时有文字时，按文字粘贴。例如从表格软件复制单元格时，剪贴板中还带一张图片，这时粘贴的是文字。文字只是图片的文件名时（复制图片文件时会带上），仍按图片粘贴
- 上传期间可以继续输入，链接插在粘贴或放下时的位置。关闭查看器时，取消未完成的上传

文件只能查看、没有修改权限时，不能插入图片，页面会说明原因。

### 目录 {#markdown-outline}

查看较长的 Markdown 文档时，正文右侧显示目录，列出一到三级标题，点击跳到对应的标题。

文档比窗口高、标题不少于 3 个时才显示目录。窗口较窄时不显示。

## 新建、移动和复制 {#organize}

页头的「新建」菜单和右键空白处，可以新建文件夹（⌥⌘N，Windows、Linux 为 Ctrl + Alt + N），也可以新建文本、Markdown、CSV、JSON、HTML 等文件。

移动和复制有几种方式：

- 拖到文件夹、面包屑或侧栏上
- ⌘C 或 ⌘X，再 ⌘V
- 右键「移动到…」「复制到…」

在 Keepbay 中复制、剪切文件后，系统剪贴板中是这些文件的名称，原来剪贴板中的内容被替换。

按 ⌘V 时，如果剪贴板中有电脑上的文件，例如截图、在访达或资源管理器中复制的文件，会上传这些文件，见[粘贴上传](./upload#paste)。否则粘贴在 Keepbay 中复制、剪切的项。

拖动时，在同一个挂载的文件夹里默认是移动，拖到另一个挂载的文件夹默认是复制。按住 ⌥（Windows、Linux 为 Ctrl）可以切换。

卡片下方会写明是"移动 3 项到「文档」"还是"复制 3 项到「文档」"，松开鼠标前可以确认。

两个挂载的文件夹之间默认复制，是因为它们往往在不同的磁盘上。如果误把几百 GB 的照片移到另一块磁盘，移回来需要很长时间。

拖到一个文件夹上停留约一秒，文件夹会自动打开，可以逐级拖入深层的子文件夹。

手机上不能拖动。长按弹出菜单（从屏幕底部弹出，项多时可以滚动），用「移动到…」「复制到…」选择目标。

这些操作都可以用 ⌘Z 撤销，见[回收站和撤销](./trash#undo)。

## 批量改名 {#batch-rename}

单个文件按 F2 或右键「改名」。需要一次改多项时，在文件夹中选中这些项，右键「批量改名…」。

对话框中有四种改名方式：

| 方式 | 说明 |
|---|---|
| 替换文字 | 把名称中的某段文字替换为另一段，可以选择区分大小写。替换为留空时，即删除这段文字 |
| 添加文字 | 在名称的开头或结尾加上一段文字。加在结尾时，放在扩展名之前 |
| 编号 | 改为"名称 + 序号"，可以设置起始数字和位数。按列表中现在的顺序编号，名称默认是当前文件夹的名称 |
| 按日期 | 改为拍摄日期或修改日期加序号，如 `2026-11-19 001`。同一天的按列表中的顺序编号，没有拍摄日期的用修改日期 |

扩展名保持不变。文件夹也可以批量改名，但只改选中的这些项，不改其中的文件和子文件夹。

对话框下方实时预览每一项改名前后的名称。以下几种情况会标出，改好之前不能确认：

- 名称不合法，如含有 `/`
- 与这次改名中另一项的新名称相同
- 与文件夹中没有选中的项重名
- 按日期改名时，这一项没有日期

预览只检查列表中显示的项。没有显示隐藏文件时，与隐藏文件重名的项不会标出，改名时这一项跳过、不覆盖，其余照常改名。以下两种情况预览中也不标出：

- 新名称会被[忽略规则](./folders#ignore)中的内置规则跳过（如 `.DS_Store`）：确认后整个改名被拒绝，并说明原因
- 新名称含有 Windows 共享（SMB）上不允许的字符：这一项改名失败，其余照常改名

一次最多改名 1000 项。

改名作为一次操作执行，可以整体撤销：点提示条上的「撤销」，或按 ⌘Z。新名称可以是另一项现在的名称，例如把 `a` 和 `b` 的名称对调，Keepbay 会按顺序处理。

[远程文件夹](./remote-folders)中，新名称不能是这次改名中另一项现在的名称，需要分两次改名。

## 复制链接 {#copy-link}

需要让家中其他成员查看某个文件或文件夹时，可以复制它在 Keepbay 中的链接发给对方。对方登录后，打开链接即可直接看到：

- 文件夹：直接进入
- 文件：打开所在的文件夹，并在查看器中打开这个文件

复制链接有三个入口：

- 右键「复制链接」。右键空白处时，复制的是当前文件夹的链接
- 信息面板中名称右侧的链接按钮
- 查看器顶栏的「更多 › 复制链接」

链接按文件本身记录，文件改名、移动后仍能打开。

这个链接不是对外的分享，打开时按各人自己的权限：对方没有权限，或者文件已删除、在回收站中时，显示"这个文件或文件夹不存在，或你已经不能访问它"。需要发给家庭以外的人时，请使用[分享链接](./share)。

链接使用「系统设置 › 通用」中的访问地址。没有设置时，使用浏览器当前的地址。在局域网中复制、发给在外面的家人时，请先设置访问地址，见[外网访问](./remote-access)。

## 只读和离线的文件夹 {#locked}

以下文件夹中的内容不能修改：

- 以只读方式添加的文件夹
- 专业版到期后的[远程文件夹](./remote-folders#license)
- 成员只获授权读取的文件夹，见[成员和权限](./members#folders)
- 离线的文件夹，包括嵌套添加在其他文件夹中、磁盘离线的文件夹，见[离线状态](./folders#offline)
- Keepbay 不能写入的文件夹，只限添加的文件夹本身，不含其中的子文件夹，见[不能写入](./folders#write-denied)

在这些文件夹中，右键菜单的新建、改名、批量改名、剪切、粘贴、移动到、移到回收站、立即删除、加水印、解压到这里显示为灰色，页头的「新建」「上传」按钮不可用，也不能把文件拖进来上传。

按对应的快捷键时，页面会提示"这个文件夹是只读的，不能修改"或"这个文件夹离线，暂时不能修改"。Keepbay 不能写入时，提示中说明原因，所有者可以点「查看存储设置」，成员的提示是请联系所有者。

只读的文件夹中，复制、复制到、下载、详情照常可用。标签保存在 Keepbay 的数据库中，所有者可以照常添加，成员不能。

离线的文件夹中，原文件在恢复在线之前无法读取，不能打开、下载和复制。已经生成的缩略图和预览图仍可查看。

文件夹离线、恢复在线，或者改为只读、恢复读写时，打开着的页面会自动更新。

## 隐藏文件和链接 {#hidden}

名称以点开头的文件和文件夹默认不显示，⇧⌘.（Windows、Linux 为 Ctrl + Shift + .）切换。

这个设置对所有文件夹生效，保存在当前浏览器中。不显示时，搜索结果中也不会出现它们。

符号链接显示为"链接"，在信息面板中可以看到它指向哪里。但不能通过它打开文件或进入文件夹，下载和分享时也会跳过。

如需访问链接指向的位置，所有者可以把那个位置单独添加为文件夹。原因见[隐私与安全](./privacy#file-access)。
