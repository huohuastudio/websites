# 离线下载 {#offline-download}

离线下载由服务器代为下载文件：提供网址、磁力链接或种子文件，服务器下载完成后放入您的文件夹。下载期间您的电脑可以关机。

安装了 yt-dlp 时，还可以下载视频网站的视频。

## 新建下载 {#new}

在侧栏的「离线下载」页点「新建下载」，或者在页头的「新建」菜单中选「离线下载…」。

可以下载的有：

- http、https 网址
- 磁力链接
- 种子文件，用「选择种子文件…」上传，最大 10 MB

一次可以粘贴多个链接，每行一个，最多 50 个。

「保存位置」默认是收件箱，可以改为其他文件夹。尚未设置收件箱时，需要先选择一个位置。

BT 下载获取到种子信息后，可以在任务的菜单中点「选择文件…」，只下载需要的那几个文件。

## 下载视频网站的视频 {#yt-dlp}

勾选「按视频网站下载」，Keepbay 会调用 yt-dlp 下载。只支持单个视频，不支持直播和包含多个视频的页面。单个视频超过 6 小时未下载完成，记为失败。

yt-dlp 不随 Keepbay 附带，需要安装在运行 Keepbay 的设备上：

```bash
pipx install yt-dlp
```

也可以从 yt-dlp 的发布页下载单个程序。安装在 PATH 以外的位置时，在「系统设置 › 离线下载」的「视频网站」一节填写 yt-dlp 路径。

安装后在同一节中点击「重新检测」，无需重启 Keepbay。

视频网站经常改版，yt-dlp 也随之频繁更新。下载失败时，先把 yt-dlp 升级到最新版本再试。

## 管理任务 {#tasks}

「离线下载」页列出所有任务和进度，可以暂停、继续、取消。取消时，已下载的部分会被删除。

暂停后，或者 Keepbay 重启后，下载从断点继续，已下载的部分不会丢失。

网络出错时会自动重试，包括首次在内最多尝试 5 次。仍然失败时，可以点「重试」，从头开始下载。

完成和取消的任务可以「清除」，失败的保留，方便重试。未清除的已结束记录保留 30 天。

每个人最多同时有 50 个未结束的下载。

## 下载完成后 {#finish}

下载过程中，文件放在目标文件夹中一个隐藏的临时文件夹里，全部下载完成后才改名放进目标文件夹，因此不会出现下载不完整的文件。

视频网站的下载有所不同：yt-dlp 先下载到数据目录的 `downloads/` 中，完成后再复制到目标文件夹。下载大视频时，数据目录所在的磁盘也需要预留足够的空间。

与目标文件夹中已有的文件重名时，不会覆盖，新文件命名为 `名称 (1)`。

## 设置 {#settings}

所有者在「系统设置 › 离线下载」中设置：

| 设置 | 说明 |
|---|---|
| 同时下载 | 默认 3 个，最多 10 个，其余的排队 |
| 速度上限 | 所有下载合计的速度上限，默认不限 |
| 单个大小上限 | 超过时停止下载，记为失败，默认不限 |
| BT 监听端口 | 1024–65535，留空时在首次下载时自动选择 |
| BT 端口映射 | 用 UPnP 在路由器上自动打开端口，可以连接更多来源，但会把这台设备的这个端口暴露到外网 |
| BT 上传速度上限 | BT 下载过程中给其他节点上传的速度 |
| yt-dlp 路径 | 留空时在 PATH 中查找，见[下载视频网站的视频](#yt-dlp) |

下载完成后不做种，也就是不再给其他人上传。这一项不能修改。

离线下载使用「系统设置 › 网络」中设置的代理，见[网络代理](./proxy)。

## 成员使用离线下载 {#members}

成员默认不能使用离线下载，需要所有者在成员的权限页打开「离线下载」，见[成员和权限](./members#features)。

离线下载会让这台设备按他人提供的链接访问外网，还会占用磁盘空间和带宽，所以默认关闭。

## 安全 {#security}

离线下载只能访问公网地址，不能访问局域网和本机的地址，比如路由器的管理页、NAS 的管理页。

这个检查在建立连接时进行，按实际连接的 IP 判断。网址跳转到内网、域名解析到内网，都会被拦截。

BT 下载同样不会连接内网地址。

Tailscale 的地址段（100.64.0.0/10）也在拦截范围内。局域网或 Tailscale 网络中的文件，建议直接把所在的文件夹添加到 Keepbay。

更多说明见[隐私与安全](./privacy#offline-download)。
