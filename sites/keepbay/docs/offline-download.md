# 离线下载 {#offline-download}

离线下载让服务器替您下载文件：给它一个网址、磁力链接或种子文件，服务器下载完放进您的文件夹。电脑可以关机，回来时文件已经在了。

装了 yt-dlp 的，还可以下载视频网站的视频。

## 新建下载 {#new}

在侧栏的「离线下载」页点「新建下载」，或者在页头的「新建」菜单中选「离线下载…」。

可以下载的有：

- http、https 网址
- 磁力链接
- 种子文件，用「选择种子文件…」上传，最大 10 MB

一次可以粘贴多个链接，每行一个，最多 50 个。

「保存位置」默认是收件箱，可以改成别的文件夹。还没有设置收件箱的，要先选一个位置。

BT 下载取到种子信息后，可以在任务的菜单中点「选择文件…」，只下载需要的那几个文件。

## 下载视频网站的视频 {#yt-dlp}

勾选「按视频网站下载」，Keepbay 会调用 yt-dlp 去下载。只下单个视频，不下直播，也不下包含多个视频的页面。一个视频超过 6 小时没下载完，记为失败。

yt-dlp 不随 Keepbay 附带，需要装在运行 Keepbay 的设备上：

```bash
pipx install yt-dlp
```

也可以从 yt-dlp 的发布页下载单个程序。装在 PATH 以外的位置的，在「系统设置 › 离线下载」的「视频网站」一节填写 yt-dlp 路径。

装好后在同一节点「重新检测」，不用重启 Keepbay。

视频网站经常改版，yt-dlp 也跟着频繁更新。下载失败时，先把 yt-dlp 升级到最新版本再试。

## 管理任务 {#tasks}

「离线下载」页列出所有任务和进度，可以暂停、继续、取消。取消时，已经下载的部分会删掉。

暂停后，或者 Keepbay 重启后，下载从断点接着进行，已经下载的部分不会丢。

网络出错时会自动重试，连同第一次最多尝试 5 次。仍然失败的，可以点「重试」，从头开始下载。

完成和取消的任务可以「清除」，失败的保留，方便重试。不清除的话，结束的记录保留 30 天。

每个人最多同时有 50 个没结束的下载。

## 下载完成后 {#finish}

下载过程中，文件放在目标文件夹中一个隐藏的临时文件夹里，全部下载完成后才改名放进目标文件夹，所以不会看到下载了一半的文件。

视频网站的下载不一样：yt-dlp 先下载到数据目录的 `downloads/` 中，完成后再复制到目标文件夹。下载大视频时，数据目录所在的磁盘也要留出足够的空间。

和目标文件夹里已有的文件重名时，不会覆盖，新文件命名为 `名称 (1)`。

## 设置 {#settings}

所有者在「系统设置 › 离线下载」中设置：

| 设置 | 说明 |
|---|---|
| 同时下载 | 默认 3 个，最多 10 个，其余的排队 |
| 速度上限 | 所有下载合计的速度上限，默认不限 |
| 单个大小上限 | 超过时停止下载，记为失败，默认不限 |
| BT 监听端口 | 1024–65535，留空时第一次下载自动选一个 |
| BT 端口映射 | 用 UPnP 在路由器上自动打开端口，能连上更多来源，但会把这台设备的这个端口暴露到外网 |
| BT 上传速度上限 | BT 下载过程中给其他节点上传的速度 |
| yt-dlp 路径 | 留空时在 PATH 中查找，见[下载视频网站的视频](#yt-dlp) |

下载完成后不做种，也就是不再给其他人上传。这一项不能改。

离线下载使用「系统设置 › 网络」中设置的代理，见[网络代理](./proxy)。

## 成员使用离线下载 {#members}

成员默认不能使用离线下载，需要所有者在成员的权限页打开「离线下载」，见[成员和权限](./members#features)。

离线下载会让这台设备按别人给的链接访问外网，还会占用磁盘空间和带宽，所以默认关闭。

## 安全 {#security}

离线下载只能访问公网地址，不能访问局域网和本机的地址，比如路由器的管理页、NAS 的管理页。

这个检查在建立连接时进行，按实际连接的 IP 判断。网址跳转到内网、域名解析到内网，都会被拦下。

BT 下载同样不会连接内网地址。

Tailscale 的地址段（100.64.0.0/10）也在拦截范围内。局域网或 Tailscale 网络里的文件，直接把那个文件夹添加到 Keepbay 更合适。

更多说明见[隐私与安全](./privacy#offline-download)。
