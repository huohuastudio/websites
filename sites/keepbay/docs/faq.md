# 常见问题 {#faq}

遇到问题时，先看两个地方：服务的日志（`sudo journalctl -u keepbay -f`，也写在数据目录的 `logs/keepbay.log` 中），和 `keepbay doctor` 的检查结果。

大部分问题在这两处都能看到原因。

这里按主题收集了大家最常问的问题。没找到答案的，欢迎发邮件到 support@huohuastudio.com 告诉我们，问的人多了就会出现在这里。

## 安装与运行 {#install}

### 运行 keepbay 提示 GLIBC_2.28 not found 或 cannot execute binary file？ {#glibc}

前者是系统太旧，glibc 低于 2.28（比如 CentOS 7、Debian 9），请换一个新一些的系统。

后者多半是下错了架构：`uname -m` 输出 `x86_64` 用 `amd64` 的安装包，`aarch64` 用 `arm64` 的安装包。

### 浏览器打不开页面？ {#cannot-open}

先在服务器上运行 `sudo -u keepbay /opt/keepbay/keepbay status`，看服务是不是在运行、监听的是哪个地址和端口。

在运行的话，通常是防火墙没有放行 8899 端口。

从 0.1.0-beta.3 之前的版本升级上来的，端口还是原来的 8790，见[升级](./upgrade#from-early-beta)。

### 设置令牌在哪里？输进去提示不正确？ {#setup-token}

令牌在服务的日志里，找 `setup_token=` 那一行，或者直接运行 `sudo -u keepbay /opt/keepbay/keepbay setup:token`。

提示不正确，通常是服务重启过：令牌每次启动都会换，日志里往上翻看到的可能是上一次的。以 `setup:token` 输出的为准。

也可以跳过令牌，直接用 `keepbay setup` 在终端里创建所有者，见[首次设置](./setup#terminal)。

### 想换个端口？ {#change-port}

重新安装一次服务，带上新的监听地址，服务文件会被覆盖并重启：

```bash
sudo /opt/keepbay/keepbay service:install --user keepbay --data-dir /var/lib/keepbay --listen 0.0.0.0:9000 --force
```

重新安装不会沿用原来服务文件中的参数，没写的就回到默认值，所以数据目录也要写上（不是默认位置的，写您自己的）。

防火墙和反向代理也要跟着改。

### 想把数据目录挪到别的磁盘？ {#move-data-dir}

停止服务，把整个数据目录搬过去，再用新位置重新安装服务：

```bash
sudo systemctl stop keepbay
sudo rsync -a /var/lib/keepbay/ /srv/keepbay-data/
sudo /opt/keepbay/keepbay service:install --user keepbay --data-dir /srv/keepbay-data --listen 0.0.0.0:8899 --force
```

监听地址同样要写上原来的值，不写会回到默认的 `0.0.0.0:8899`。

确认一切正常后，再删除原来的目录。之后运行命令时都要加 `--data-dir /srv/keepbay-data`。

### 能不能用 Docker 部署？ {#docker}

目前不提供 Docker 镜像，以后会考虑提供。

Keepbay 本身就是一个程序加一个 `lib/` 目录，没有别的依赖。用 Docker 主要是多了一层文件属主（PUID、PGID）和目录映射要处理，配错了反而更麻烦。

### 支持 Windows 或 macOS 吗？ {#platforms}

目前只提供 Linux 的安装包（x86_64 和 arm64）。家里只有 Windows 或 Mac 的，可以装在 NAS、软路由或一台小主机上。

### 有手机 App 吗？ {#mobile}

暂时没有。网页在手机浏览器上可以正常使用，上传、预览、分享都没问题。

## 登录与帐号 {#login}

### 经反向代理访问，登录时提示"请求来源不正确"？ {#csrf-rejected}

没有设置可信代理。

Keepbay 默认不信任 `X-Forwarded-*` 请求头，以为自己在 `http://127.0.0.1:8899`，浏览器却说请求来自 `https://您的域名`，对不上就拒绝了。

按[外网访问](./remote-access#trusted-proxies)设置 `KEEPBAY_TRUSTED_PROXIES` 后重启即可。设置了还提示的，检查代理是否原样转发了 `Host`、是否带了 `X-Forwarded-Proto`。

### 忘记了密码？被锁定了？ {#forgot-password}

成员忘了密码，所有者在成员页给他重设就行。所有者自己忘了：

```bash
sudo systemctl stop keepbay
sudo -u keepbay /opt/keepbay/keepbay user:reset-password <用户名>
sudo systemctl start keepbay
```

会生成一个随机的新密码，同时关闭两步验证、退出所有设备上的登录。

被锁定的话，等 15 分钟，或者运行 `keepbay user:unlock <用户名>`。

手机丢了、两步验证用不了，先用恢复码登录；恢复码也找不到，运行 `keepbay user:2fa-off <用户名>`。各命令的说明见[命令行](./cli#user)。

### 两步验证的验证码总是不正确？ {#totp}

先看手机的时间准不准，验证码只允许前后差 30 秒左右。

另外同一个验证码只能用一次，刚用过的那个再输一遍会被拒绝，请等下一个。

### 用 IP 访问时不能添加通行密钥？ {#passkey-ip}

通行密钥绑定在域名上，浏览器只在 HTTPS 或 `localhost` 下允许使用，IP 地址不行。需要一个经过 HTTPS 的域名，见[外网访问](./remote-access#passkey)。

### 所有者能不能关掉密码，只用通行密钥或外部帐号登录？ {#owner-password}

不能，所有者必须保留密码登录。成员可以关闭密码登录。

通行密钥跟着设备走，外部帐号跟着身份提供方走。手机换了或身份提供方出了问题时，还能用密码登录。

### 用外部帐号登录，提示没有对应的帐号？ {#oidc-not-linked}

Keepbay 不会按邮箱自动把外部帐号和已有帐号对上，否则有人在身份提供方那边改个邮箱就能登进来。

先用密码登录，在「个人设置 › 安全」中关联这个外部帐号，以后就能直接用它登录了。

想让家人第一次用外部帐号登录时自动建帐号，所有者可以在「系统设置 › 外部登录」中打开自动建号，并限定允许的邮箱或域名。

### 添加成员时提示"最多 2 位用户（含所有者），已经满了"？ {#user-limit}

免费版最多 2 个用户，所有者算一个，所以只能再加一位家人。专业版不限用户数。

### 成员登录时提示"帐号已暂停"？ {#account-suspended}

专业版到期、降级为免费版后，用户数超出了 2 个，多出来的成员会暂停登录。帐号、文件和数据都保留着，一个都没删。

所有者可以在成员的菜单中「改为保留这位」，换一个人继续用。重新激活专业版后，全部自动恢复。

### 成员第一次登录，要改密码吗？ {#member-first-login}

不强制。所有者添加成员时设一个初始密码告诉对方，对方登录后可以在「个人设置 › 帐号」中改。

建议让家人登录后改掉，再开启两步验证或添加通行密钥。

### 外部登录的回调地址填什么？提示回调地址不匹配？ {#oidc-callback}

回调地址在「系统设置 › 外部登录」的最上面，格式是 `https://您的域名/api/v1/auth/oidc/callback`。

它是按您当前访问 Keepbay 的地址算出来的。用 IP 打开 Keepbay 时复制的地址，和用域名访问时的不一样，提供方会提示不匹配。

请用以后实际访问的域名打开 Keepbay，再复制回调地址。经反向代理访问的，还要设置可信代理，见[外部帐号登录](./sso#callback)。

### 用 Microsoft 帐号登录，自动建号没有生效？ {#oidc-microsoft}

自动建号要求提供方确认过邮箱（`email_verified`），Microsoft 的登录信息中通常没有这一项。

请先给家人建好帐号，让他们用密码登录后，在「个人设置 › 安全」中关联 Microsoft 帐号。之后就能直接用 Microsoft 帐号登录了。

## 文件与文件夹 {#files}

### 添加文件夹时提示没有权限？ {#path-denied}

Keepbay 以 `keepbay` 用户运行，只能访问这个用户有权限的文件夹。

给文件夹授权时别漏了上级目录：比如文件夹在 `/home/alice/photos`，`/home` 和 `/home/alice` 都要让 `keepbay` 用户能进入（`x` 权限）。命令见[安装](./install#permissions)。

后来用 `cp -p`、`rsync -a` 复制进去的文件会带着原来的权限，Keepbay 可能又读不了了，复制完再授权一次。

### 能管理 S3、百度网盘、阿里云盘上的文件吗？ {#cloud}

Keepbay 不直接连接云存储，但可以先把它们变成服务器上的文件夹：用 rclone 同步到本地或者挂载，国内网盘再经 OpenList 转一下。

能接入的服务和具体做法，见[云盘和对象存储](./cloud-storage)。

### Keepbay 会改动我文件夹里的东西吗？ {#modify-files}

只在您让它改的时候改：上传、新建、改名、移动、删除，或者您确认了收件箱、AI 桌面给出的整理计划。

它不会自己去"整理"您已有的文件夹。

为了做到删除可恢复、上传不留半截文件，Keepbay 会在您的文件夹里放几样东西：

- `.keepbay-trash/` 是回收站
- 上传、复制过程中会出现 `.keepbay-` 开头的临时文件，完成后改名成正式的名字

这些都不会出现在 Keepbay 的文件列表里。

以只读方式添加的文件夹，Keepbay 不做任何写入。

### 回收站在哪里，保留多久？ {#trash}

在添加给 Keepbay 的文件夹根目录的 `.keepbay-trash/` 中。文件夹里还挂着别的磁盘的，那块磁盘上的文件放在它自己根目录的 `.keepbay-trash/` 中。

总之回收站和文件在同一块磁盘上，删除只是改个名，再大的文件夹也很快。

默认保留 30 天，所有者可以在「系统设置 › 存储」中修改，也可以设为永不清理。

它和 NAS 自带的回收站互不相干。在 Keepbay 里删除的进 Keepbay 的回收站，在 NAS 文件管理里删除的进 NAS 的回收站。

### 文件夹显示"离线"？ {#offline}

Keepbay 发现文件夹不对劲时会先标记离线，停止写入和清理，避免把文件写到错误的地方。常见的原因：

- **找不到文件夹**：硬盘没有接上或没有挂载，接上后自动恢复
- **磁盘换了**、**文件夹突然变空**：多半是硬盘没挂上，看到的是挂载点下面的空目录。这时如果往里写文件，等硬盘挂上，这些文件就被盖住了。确实换了硬盘或清空了文件夹的，在「系统设置 › 存储」中点「确认恢复」
- **无法读取**：权限变了
- **路径指向了别处**：路径中的符号链接被改了，为安全起见暂停使用

### 拔掉移动硬盘，索引会被清空吗？ {#unplug}

不会。硬盘拔掉后文件夹标记为离线，索引、标签、AI 结果原样保留，什么都不清理。

重新接上后自动恢复，接着用。

### 在外面改了文件，Keepbay 里没变化？ {#not-updated}

本地磁盘上的改动一般几秒内就能看到。没变化的情况有两种：

一是文件夹在 SMB、NFS 等网络磁盘上，收不到变化通知，要等定期补扫（默认 6 小时，可以在文件夹的设置中改短）。

等不及就在「系统设置 › 存储」中点「立即扫描」，或运行 `keepbay index:rescan <文件夹>`。

二是文件夹太多，超过了系统的监听上限，见下一条。

### 提示"文件夹太多，部分文件夹的变化无法立即发现"？ {#inotify}

Linux 给每个目录的监听数量设了上限（`fs.inotify.max_user_watches`），目录很多时会用完，用不上监听的目录只能靠定期补扫。

调大这个上限即可：

```bash
# 立即生效
sudo sysctl fs.inotify.max_user_watches=524288

# 重启后仍然有效
echo 'fs.inotify.max_user_watches=524288' | sudo tee /etc/sysctl.d/90-keepbay-inotify.conf
```

然后重启 Keepbay。

### 在外面改名、移动了文件，标签会丢吗？ {#rename-outside}

在同一个文件夹（添加给 Keepbay 的那个）、同一块磁盘里改名或移动，不会丢。

Keepbay 按设备号和 inode 认出这是同一个文件，原来打的标签、AI 的结果都跟着走。在访达、资源管理器、NAS 文件管理里移动都没关系。

挪到另一个添加的文件夹，或者挪到另一块磁盘上，在 Keepbay 看来就是删了一个、又来了一个新的，标签不会跟过去。

这种移动请在 Keepbay 里做，它会把标签一起带走。

### 可以同时让 Jellyfin、Syncthing、相册程序用同一个文件夹吗？ {#other-apps}

可以。Keepbay 只读取和建立索引，不会挪动文件，其他程序该怎么用还怎么用。

Syncthing 同步时的临时文件、群晖和威联通生成的缩略图目录，Keepbay 都会自动跳过。

### 为什么有些文件搜不到？ {#search-missing}

先看看是不是这几种情况：

- 文件夹还在扫描，侧栏的「后台任务」里有进度
- 文件在默认跳过的目录里，比如 `node_modules`、`.git`、照片图库
- 搜的是文件内容，而这个文件没有文字层（扫描件、图片）。免费版只能搜到有文字层的文档；图片里的文字要专业版的[文字识别](./semantic-search#ocr)，扫描版 PDF 目前不识别

### 上传到一半断网了？ {#upload-interrupted}

不需要处理。上传是分块进行的，网络断了会自动重试，恢复后从断点继续，不用从头传。

重试几次仍然失败的，在传输面板中点继续即可。

### 新建文件时提示"这个名称会被内置规则忽略"？ {#ignored-name}

`.DS_Store`、下载到一半的 `*.part` 这类名称是 Keepbay 默认跳过的。用它们新建文件，会让文件"消失"在列表里，所以不能使用，请换一个名字。

### 按 ⌘Z 撤销不了之前的操作？ {#undo-missing}

撤销记录保存在当前浏览器标签页中，最多记最近 50 步。换了标签页、关掉标签页后，之前的操作就撤销不了了。

撤销也只对自己做的操作有效，家人删除的文件不能用您的 ⌘Z 撤销，到回收站中恢复即可。

打标签、删除标签、立即删除不能撤销。

### 想改一下文件夹的路径？ {#change-mount-path}

文件夹添加后路径不能改。要先在「系统设置 › 存储」中移除，再用新路径添加。

移除会删除这个文件夹的索引，文件上的标签、AI 的结果、给成员的授权也会一起删除，磁盘上的文件不受影响。重新添加后，要重新扫描、重新授权。

只是硬盘换了挂载点的，可以在系统中把它挂回原来的路径，就不用移除了。

### 打包下载提示"一次选的项太多"？ {#zip-too-many}

一次最多选 1000 项打包下载。选它们所在的文件夹下载，就没有这个限制。

## 预览与媒体 {#media}

### 视频没有缩略图，HEIC 照片打不开？ {#ffmpeg}

这两样都要靠系统中的 ffmpeg，Keepbay 不附带（HEVC 解码涉及专利授权）。装上就好：

```bash
sudo apt install ffmpeg      # Debian、Ubuntu
```

HEIC 还要求 ffmpeg 7.1 及以上、带 HEVC 解码器，老系统源里的版本可能不够新。

装好或升级后，在「系统设置 › 媒体处理」中点「重新检测」，不用重启，之前没处理的文件会自动补上。

### 所有照片都没有缩略图，提示"安全限制没有启用"？ {#sandbox}

内核不支持 seccomp，处理照片的子进程没法被隔离。Keepbay 不会在没有隔离的情况下解码照片和视频，所以不处理。

浏览器能直接显示的图片（JPEG、PNG 等）和视频照样能点开预览，文件照常浏览和下载。

这在部分 NAS（如群晖 DS918+、DS920+）上会遇到，原因和取舍见[隐私与安全](./privacy#sandbox)。

### 某张超大的图片没有缩略图？ {#max-pixels}

像素超过上限的图片只读取尺寸，不生成缩略图，免得一张几亿像素的全景图把内存占满。

上限约 2.68 亿像素，在「系统设置 › 媒体处理」中可以看到，不能修改。这样的图片照样可以下载，用电脑上的看图软件打开。

### MKV、AVI 视频播放不了？ {#mkv}

Keepbay 不转码视频，只能在浏览器中直接播放 MP4、MOV、WebM 等浏览器支持的格式。

MKV、AVI 请下载后用播放器打开。转码很占 CPU，放在 NAS 上会很慢，所以目前没有做。

### 能看压缩包里有什么吗？ {#archive}

目前不能预览压缩包的内容。可以右键「解压到这里」或「解压到收件箱」，在后台解压。

支持 zip、tar、tar.gz、tar.bz2，不支持 rar、7z 和加了密码的压缩包。

### .doc、.ppt 打不开？ {#old-office}

Word 只支持 .docx，PowerPoint 只支持 .pptx，老的 .doc、.ppt 只能下载后打开。Excel 的 .xls 可以预览。

演示文稿的预览只显示文字和图片，不还原动画和版式。

## 分享与通知 {#sharing}

### 分享出去的照片会带拍摄地点吗？ {#share-location}

不加水印的话，访客下载的是原图，照片中记录的拍摄地点也在里面。分享带拍摄地点的照片时，Keepbay 会提醒您。

在分享链接中打开「给图片加水印」（专业版），访客拿到的是不带任何拍摄信息的图片。

### 分享链接提示"只有连着同一个网络的人能打开"？ {#share-lan}

您是用局域网地址打开 Keepbay 的，比如 `192.168.1.10` 或 `nas.local`，分享链接也是这个地址，外面的人打不开。

请用外网能访问的域名打开 Keepbay，再创建分享链接，见[外网访问](./remote-access)。

### 能用分享链接让别人给我传文件吗？ {#share-upload}

目前不能。访客只能浏览和下载，不能上传、修改和删除。

### 别人说分享链接打不开了？ {#share-broken}

在「个人设置 › 分享链接」中找到这条链接，看它的状态：过期了、下载次数用完了，还是被停用了。

成员建的链接，在所有者关掉他的「创建分享链接」权限、或者停用他的帐号后，也会失效。

### 收不到通知？ {#notify-missing}

先在「个人设置 › 通知」中，点渠道的「发一条试试」。渠道列表中会显示最近一次发送失败的原因。

再看「接收哪些通知」中，这类通知有没有打开。"后台任务完成"和"分享链接被访问"默认是关的。

邮件收不到的，看看垃圾邮件。邮件不经过代理，发件服务器要能直接连上。

## 升级与备份 {#maintenance}

### 网页上提示不能更新，要手动升级？ {#update-blocked}

最常见的是运行服务的 `keepbay` 用户不能写入安装目录，运行页面上给的 `sudo chown -R keepbay: /opt/keepbay` 后刷新即可。

从 0.1.0-beta.3 之前的版本升级上来的，安装方式不同，要手动升级一次，见[升级](./upgrade#blocked)。

### 检查更新失败？ {#update-check-failed}

Keepbay 要连授权中心 `huohuastudio.com` 查询新版本。

服务器访问外网要经过代理的，在「系统设置 › 网络」中设置代理，或者让服务带上 `HTTPS_PROXY` 环境变量。

### 数据库备份在哪里？会备份我的文件吗？ {#backup}

默认每天凌晨 3 点后自动备份一次数据库，保留最近 7 份，放在数据目录的 `backups/` 中。

频率、份数和备份目录可以在「系统设置 › 维护」中修改。备份目录可以放到别的磁盘，但不能放在添加给 Keepbay 的文件夹里，否则成员浏览那个文件夹就能拿到整个数据库。

备份的只是数据库：索引、标签、整理记录、设置、帐号。

**您的文件本身不在备份范围内**，它们本来就在您的文件夹里，请用 NAS 的快照、rsync 或别的备份工具备份它们。Keepbay 是网盘，不是备份软件。

### 能在网页上下载数据库备份吗？ {#backup-download}

不能。数据库中有全部的索引、帐号和设置，我们不想让它能从浏览器中被一键拿走。

需要的话，在服务器上直接复制备份目录中的文件，默认是数据目录下的 `backups/`。

### 怎么用备份恢复？ {#restore}

网页上不能恢复，要在服务器上用命令行：停止服务，运行 `keepbay db:restore`，在列表中选一份备份，再启动服务。

详见[命令行](./cli#db-restore)。

### 换到新服务器后，AI 厂商的 Key 没了，两步验证也登不进去？ {#secret-key}

只复制了数据库，没有带上数据目录中的 `secret.key`。这些配置是用它加密的，换了密钥就解不开了。

把原来的 `secret.key` 复制过来重启即可。原来的找不到了，就重新填写这些配置，开了两步验证的帐号用恢复码登录。

所以迁移时最省事的做法是整个数据目录一起搬，见[安装](./install#data-dir)。

## 专业版与 AI {#pro}

### 免费版能用 AI 功能吗？ {#free-ai}

不能。语义搜索、按画面搜图、识别图片中的文字、AI 桌面、收件箱自动整理、AI 标签、重要日期提醒，连同 AI 模型的设置，都属于专业版。

免费版里不会出现这些入口，功能对比只放在授权页。

### 激活时提示设备数已满？ {#device-limit}

一个授权码可以激活的设备数有上限。

到授权中心网站上解绑不再使用的设备，或者把它换绑为这台设备的安装 ID，再回来激活。

### 重装系统后，专业版没了？ {#reinstall-license}

全新安装会生成新的安装 ID，原来的授权证书对它无效，需要重新激活一次。这会占用一个设备名额，旧的那台请到网站上解绑。

如果是把整个数据目录原样搬过来，安装 ID 不变，不用重新激活。

### 更新服务到期了，专业版还能用吗？ {#updates-expired}

能。专业版是永久使用的，到期的只是更新服务。

您装的版本照常使用，专业版的功能照常可用，安全修复也照常可以装。之后发布的新功能版本，续费后才能装。见[专业版](./pro#license-model)。

### 授权页显示"专业版 · 已暂停"？ {#pro-paused}

您装的版本是在更新服务截止之后发布的，专业版的功能暂停，文件和数据都保留。

续费更新服务后，在「系统设置 › 授权」中点「立即续期」；或者换回截止日之前发布的版本。

换回旧版本时，已经被新版本升级过数据库的，旧版本打不开，要先用升级前的备份恢复，备份之后的改动会丢失，见[升级](./upgrade#database)。

### 怎么把专业版转到新服务器？ {#transfer-license}

在旧服务器的「系统设置 › 授权」中点「在本机停用专业版」，再到授权中心网站上解绑旧设备，然后在新服务器上激活。

整个数据目录原样搬过去的，安装 ID 不变，不用重新激活。见[专业版](./pro#devices)。

### 云端 AI 会拿我的文件去训练模型吗？ {#cloud-ai-training}

这取决于您选的 AI 厂商的数据使用政策，请查看厂商的说明。

Keepbay 这边：默认用本地模型，什么都不发；您选择用云端模型时，在界面上写清楚每项功能发送什么；自动整理、AI 标签、日期提醒这几项后台功能，还要再逐项允许一次。语义搜索选了云端的向量模型的，建立索引时会把文件中的文字发出去，见[语义搜索](./semantic-search#cloud-embedding)。

介意的话，就只用本地模型或者家里自己跑的 Ollama。详见[隐私与安全](./privacy#ai)。

### 提示"本月的 AI 花费已达上限"？ {#ai-budget}

这是所有者设置的每月花费上限起了作用，下个月自动恢复。

需要的话，所有者可以在「系统设置 › AI 模型」中调高上限。用本地模型不花钱，不受这个限制。

### 成员提示"还没有使用云端 AI 的权限"？ {#ai-cloud-not-allowed}

成员默认不能使用云端 AI，因为这会让他的文件离开这台设备。

所有者在成员详情中打开「使用云端 AI」即可；或者给这项功能换成本地模型，用本地模型不需要这个权限。

## 其他 {#others}

### 离线下载提示"不能下载局域网或本机上的地址"？ {#url-blocked}

离线下载只能访问公网地址，防止有人借它去访问您内网里的路由器管理页、NAS 管理页之类的地方。

Tailscale 的地址（100.64.0.0/10 网段）也在此列，所以离线下载连不到您 Tailscale 网络中的设备。局域网里的文件，直接把那个文件夹添加到 Keepbay 更合适。

### Keepbay 会收集我的使用数据吗？ {#telemetry}

不会。程序里没有统计、遥测、崩溃上报，网页也不加载任何第三方的东西。我们也不知道您装了几台。

它什么时候联网、发了什么，见[隐私与安全](./privacy#outbound)。

### 卸载了 Keepbay，我的文件还在吗？ {#uninstall}

在，一个都不少。Keepbay 从来不把文件搬进自己的存储，文件夹里的文件原样不动，卸载只删程序和数据目录（索引、缩略图、设置）。

文件夹中的 `.keepbay-trash/` 是回收站，里面是您删除过的文件，确认不需要了可以一并删除。
