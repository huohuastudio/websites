# 常见问题 {#faq}

遇到问题时，先看两个地方：服务的日志（`sudo journalctl -u keepbay -f`，也写在数据目录的 `logs/keepbay.log` 中），和 `keepbay doctor` 的检查结果。

大部分问题在这两处都能看到原因。

这里按主题收集了常见的问题。如果没有找到答案，请在 [GitHub](https://github.com/huohuastudio/keepbay-releases/issues) 上提交 Issue，不便公开的内容请发邮件到 support@huohuastudio.com。我们会把常见的问题补充到这里。

在 Keepbay 的「系统设置 › 关于」中点「提交问题」，也可以打开这个页面。提交时请附上同一页中「复制版本信息」复制的内容。

## 安装与运行 {#install}

### 运行 keepbay 提示 GLIBC_2.28 not found 或 cannot execute binary file？ {#glibc}

前者是系统版本过旧，glibc 低于 2.28（比如 CentOS 7、Debian 9），请换用较新的系统。

后者通常是安装包的架构不对：`uname -m` 输出 `x86_64` 时用 `amd64` 的安装包，输出 `aarch64` 时用 `arm64` 的安装包。

### 浏览器打不开页面？ {#cannot-open}

先在服务器上运行 `sudo -u keepbay /opt/keepbay/keepbay status`，查看服务是否在运行，以及监听的地址和端口。

如果服务在运行，通常是防火墙没有放行 8899 端口。

从 0.1.0-beta.3 之前的版本升级的，端口仍是原来的 8790，见[升级](./upgrade#from-early-beta)。

### 设置令牌在哪里？输进去提示不正确？ {#setup-token}

令牌在服务的日志里，找 `setup_token=` 那一行，或者运行 `sudo -u keepbay /opt/keepbay/keepbay setup:token`。

提示不正确，通常是因为服务重启过：令牌在每次启动时重新生成，日志中较早的记录可能是上一次的令牌。请以 `setup:token` 的输出为准。

也可以跳过令牌，直接用 `keepbay setup` 在终端里创建所有者，见[首次设置](./setup#terminal)。

### 想换个端口？ {#change-port}

重新安装一次服务，带上新的监听地址，服务文件会被覆盖并重启：

```bash
sudo /opt/keepbay/keepbay service:install --user keepbay --data-dir /var/lib/keepbay --listen 0.0.0.0:9000 --force
```

重新安装不会沿用原来服务文件中的参数，未指定的参数会恢复为默认值，所以数据目录也要写上（如果不在默认位置，请写实际的路径）。

防火墙和反向代理的设置也要相应修改。

### 想把数据目录挪到别的磁盘？ {#move-data-dir}

停止服务，将整个数据目录复制到新位置，再用新位置重新安装服务：

```bash
sudo systemctl stop keepbay
sudo rsync -a /var/lib/keepbay/ /srv/keepbay-data/
sudo /opt/keepbay/keepbay service:install --user keepbay --data-dir /srv/keepbay-data --listen 0.0.0.0:8899 --force
```

监听地址同样要写上原来的值，否则会恢复为默认的 `0.0.0.0:8899`。

确认一切正常后，再删除原来的目录。之后运行命令时都要加 `--data-dir /srv/keepbay-data`。

### 能不能用 Docker 部署？ {#docker}

目前不提供 Docker 镜像，以后会考虑提供。

Keepbay 由一个程序和一个 `lib/` 目录组成，没有其他依赖。使用 Docker 会多出文件属主（PUID、PGID）和目录映射的配置，配置有误时排查更复杂。

### 支持 Windows 或 macOS 吗？ {#platforms}

目前只提供 Linux 的安装包（x86_64 和 arm64）。如果家中只有 Windows 或 Mac 电脑，可以安装在 NAS、软路由或一台小主机上。

### 有手机 App 吗？ {#mobile}

暂时没有。网页可以在手机浏览器上正常使用，支持上传、预览和分享。

## 登录与帐号 {#login}

### 经反向代理访问，登录时提示"请求来源不正确"？ {#csrf-rejected}

原因是没有设置可信代理。

Keepbay 默认不信任 `X-Forwarded-*` 请求头，因此会认为自己的地址是 `http://127.0.0.1:8899`，而浏览器发来的请求来源是 `https://您的域名`，两者不一致，请求会被拒绝。

按[外网访问](./remote-access#trusted-proxies)设置 `KEEPBAY_TRUSTED_PROXIES` 后重启即可。设置后仍有提示的，请检查代理是否原样转发了 `Host`、是否带了 `X-Forwarded-Proto`。

### 忘记了密码？被锁定了？ {#forgot-password}

成员忘记密码时，由所有者在成员页为其重设密码。所有者忘记密码时：

```bash
sudo systemctl stop keepbay
sudo -u keepbay /opt/keepbay/keepbay user:reset-password <用户名>
sudo systemctl start keepbay
```

会生成一个随机的新密码，同时关闭两步验证、退出所有设备上的登录。

帐号被锁定时，等待 15 分钟，或者运行 `keepbay user:unlock <用户名>`。

手机丢失、无法完成两步验证时，请先用恢复码登录；恢复码也找不到时，运行 `keepbay user:2fa-off <用户名>`。各命令的说明见[命令行](./cli#user)。

### 两步验证的验证码总是不正确？ {#totp}

请先检查手机的时间是否准确，验证码只允许前后约 30 秒的误差。

另外，同一个验证码只能使用一次，再次输入刚用过的验证码会被拒绝，请等待下一个验证码。

### 用 IP 访问时不能添加通行密钥？ {#passkey-ip}

通行密钥绑定在域名上，浏览器只在 HTTPS 或 `localhost` 下允许使用，通过 IP 地址访问时不能使用。需要一个通过 HTTPS 访问的域名，见[外网访问](./remote-access#passkey)。

### 所有者能不能关掉密码，只用通行密钥或外部帐号登录？ {#owner-password}

不能，所有者必须保留密码登录。成员可以关闭密码登录。

通行密钥依赖设备，外部帐号依赖身份提供方。更换手机或身份提供方出现故障时，仍然可以用密码登录。

### 用外部帐号登录，提示没有对应的帐号？ {#oidc-not-linked}

Keepbay 不会按邮箱自动将外部帐号与已有帐号关联，否则他人只要在身份提供方修改邮箱，就能登录对应的帐号。

先用密码登录，在「个人设置 › 安全」中关联这个外部帐号，之后即可直接用它登录。

如果希望家人首次用外部帐号登录时自动创建帐号，所有者可以在「系统设置 › 外部登录」中打开自动建号，并限定允许的邮箱或域名。

### 添加成员时提示"最多 2 位用户（含所有者），已达上限"？ {#user-limit}

免费版最多 2 个用户，所有者算一个，因此只能再添加一位家人。专业版不限用户数。

### 成员登录时提示"帐号已暂停"？ {#account-suspended}

专业版到期、降级为免费版后，用户数超出了 2 个，超出的成员会被暂停登录。他们的帐号、文件和数据都会保留，不会被删除。

所有者可以在成员的菜单中点「改为保留此成员」，更换保留的成员。重新激活专业版后，所有成员自动恢复。

### 成员第一次登录，要改密码吗？ {#member-first-login}

不强制。所有者添加成员时设置初始密码并告知对方，对方登录后可以在「个人设置 › 帐号」中修改。

建议家人登录后修改密码，并开启两步验证或添加通行密钥。

### 外部登录的回调地址填什么？提示回调地址不匹配？ {#oidc-callback}

回调地址在「系统设置 › 外部登录」的最上面，格式是 `https://您的域名/api/v1/auth/oidc/callback`。

回调地址根据您当前访问 Keepbay 的地址生成。通过 IP 访问时复制的地址与通过域名访问时不同，提供方会因此提示不匹配。

请用以后实际访问的域名打开 Keepbay，再复制回调地址。经反向代理访问的，还要设置可信代理，见[外部帐号登录](./sso#callback)。

### 用 Microsoft 帐号登录，自动建号没有生效？ {#oidc-microsoft}

自动建号要求提供方确认过邮箱（`email_verified`），Microsoft 的登录信息中通常没有这一项。

请先给家人建好帐号，让他们用密码登录后，在「个人设置 › 安全」中关联 Microsoft 帐号。之后即可直接用 Microsoft 帐号登录。

## 文件与文件夹 {#files}

### 添加文件夹时提示没有权限？ {#path-denied}

Keepbay 以 `keepbay` 用户运行，只能访问这个用户有权限的文件夹。

页面提示没有权限时，下面会显示一条填好路径的授权命令，将命令复制到服务器上以 root 运行，再点一次添加即可。这条命令也会为上级目录加上进入权限，说明见[安装](./install#permissions)。

之后用 `cp -p`、`rsync -a` 复制进去的文件会保留原来的权限，Keepbay 可能无法读取，复制完成后请再运行一次这条命令。

如果文件夹位于 FAT、exFAT、NTFS 格式的 U 盘或移动硬盘上，授权命令无法设置权限，需要在挂载时把所有者设为 `keepbay`。网络盘和云盘的情况见[安装](./install#permissions)。

### 上传、移动时提示"Keepbay 没有这个文件夹的写入权限"？ {#write-denied}

`keepbay` 用户能读取这个文件夹，但不能写入。常见的原因是授权时只给了读取权限，或者之后文件夹的所有者、权限被改动。

远程文件夹中出现这个提示，是存储拒绝了写入，请在存储上检查访问密钥或帐号的权限，下面的授权命令不适用。

在「系统设置 › 存储」中，这个文件夹下会显示填好路径的授权命令。复制到服务器上以 root 运行即可，无需重启。不需要在 Keepbay 中修改文件时，也可以把文件夹改为只读。

存储页只检查文件夹本身。只有其中某个子文件夹不能写入时，存储页不提示，对这个子文件夹操作时才会提示。授权命令对整个文件夹生效，另外挂载的磁盘和绑定挂载的目录除外，见[安装](./install#permissions)。

文件夹所在的文件系统是只读挂载的（如光盘、只读挂载的网络盘），授权无法解决，请把文件夹改为只读。

### 能管理 S3、WebDAV、SFTP、百度网盘、阿里云盘上的文件吗？ {#cloud}

S3 兼容的对象存储（Amazon S3、Cloudflare R2、阿里云 OSS、腾讯云 COS、MinIO 等）、WebDAV（坚果云、Nextcloud、群晖 NAS 等）和 SFTP（能用 SSH 登录的 NAS、VPS），专业版可以直接添加，见[远程文件夹](./remote-folders)。

国内网盘不能直接连接，要先添加到 OpenList。专业版可以将 OpenList 的 WebDAV 添加为远程文件夹；也可以用 rclone 把它同步到本地或挂载，接入为服务器上的文件夹。能接入的服务和具体做法，见[云盘](./cloud-storage)。

### Keepbay 会改动我文件夹里的东西吗？ {#modify-files}

只在以下情况下改动：您执行上传、新建、改名、移动、删除，您确认 AI 桌面列出的计划，或者收件箱按您的设置整理其中的文件（开启自动模式时，命中规则的文件会直接移动，不再逐个确认）。

Keepbay 不会主动整理收件箱以外的文件夹。

为了让删除的文件可以恢复、上传中断时不留下不完整的文件，Keepbay 会在您的文件夹中创建以下内容：

- `.keepbay-trash/` 是回收站
- 上传、复制过程中会出现 `.keepbay-` 开头的临时文件，完成后重命名为正式的文件名

这些都不会出现在 Keepbay 的文件列表里。

以只读方式添加的文件夹，Keepbay 不做任何写入。

### 回收站在哪里，保留多久？ {#trash}

在添加给 Keepbay 的文件夹根目录的 `.keepbay-trash/` 中。如果文件夹中挂载了其他磁盘，那块磁盘上的文件放在该磁盘根目录的 `.keepbay-trash/` 中。

回收站和文件始终在同一块磁盘上，删除只是重命名，文件夹再大也能很快完成。

默认保留 30 天，所有者可以在「系统设置 › 存储」中修改，也可以设为永不清理。

Keepbay 的回收站与 NAS 自带的回收站相互独立。在 Keepbay 中删除的文件进入 Keepbay 的回收站，在 NAS 文件管理中删除的文件进入 NAS 的回收站。

### 文件夹显示"离线"？ {#offline}

Keepbay 检测到文件夹异常时，会先将其标记为离线，停止写入和清理，避免把文件写到错误的位置。常见的原因：

- **找不到文件夹**：硬盘没有接上或没有挂载，接上后自动恢复
- **磁盘已更换**、**文件夹突然变空**：通常是硬盘没有挂载，看到的是挂载点下的空目录。此时如果写入文件，硬盘挂载后这些文件会被遮盖。如果确实更换了硬盘或清空了文件夹，在「系统设置 › 存储」中点「确认恢复」
- **无法读取**：权限发生了变化
- **路径指向了别处**：路径中的符号链接被修改，为安全起见暂停使用

### 拔掉移动硬盘，索引会被清空吗？ {#unplug}

不会。硬盘拔下后，文件夹被标记为离线，索引、标签、AI 结果全部保留，不做任何清理。

重新接上后自动恢复，可以继续使用。

### 在外面改了文件，Keepbay 里没变化？ {#not-updated}

本地磁盘上的改动一般几秒内就能看到。没有变化的情况有两种：

一是文件夹在 SMB、NFS 等网络磁盘上，收不到变化通知，需要等待定期补扫（默认 6 小时，可以在文件夹的设置中改短）。

需要立即更新时，在「系统设置 › 存储」中点「立即扫描」，或运行 `keepbay index:rescan <文件夹>`。

二是文件夹太多，超过了系统的监听上限，见下一条。

### 提示"文件夹太多，部分文件夹的变化无法立即发现"？ {#inotify}

Linux 给每个目录的监听数量设了上限（`fs.inotify.max_user_watches`），目录很多时会达到上限，超出上限的目录只能依靠定期补扫。

调大这个上限即可：

```bash
# 立即生效
sudo sysctl fs.inotify.max_user_watches=524288

# 重启后仍然有效
echo 'fs.inotify.max_user_watches=524288' | sudo tee /etc/sysctl.d/90-keepbay-inotify.conf
```

然后重启 Keepbay。

### 在外面改名、移动了文件，标签会丢吗？ {#rename-outside}

在同一个文件夹（添加给 Keepbay 的那个）、同一块磁盘里改名或移动，不会丢。

Keepbay 根据设备号和 inode 识别出这是同一个文件，原有的标签和 AI 结果都会保留。在访达、资源管理器或 NAS 文件管理中移动均可。

如果移动到另一个已添加的文件夹或另一块磁盘上，Keepbay 会将其视为删除了一个文件、新增了一个文件，标签不会保留。

这类移动请在 Keepbay 中操作，标签会随文件一起移动。

### 可以同时让 Jellyfin、Syncthing、相册程序用同一个文件夹吗？ {#other-apps}

可以。Keepbay 只读取文件和建立索引，不会移动文件，不影响其他程序的使用。

Syncthing 同步时的临时文件、群晖和威联通生成的缩略图目录，Keepbay 都会自动跳过。

### 为什么有些文件搜不到？ {#search-missing}

请先确认是否属于以下情况：

- 文件夹还在扫描，侧栏的「后台任务」里有进度
- 文件在默认跳过的目录里，比如 `node_modules`、`.git`、照片图库
- 搜的是文件内容，而这个文件没有文字层（扫描件、图片）。免费版只能搜到有文字层的文档；图片里的文字要专业版的[文字识别](./semantic-search#ocr)，扫描版 PDF 目前不识别

### 上传到一半断网了？ {#upload-interrupted}

无需处理。上传是分块进行的，网络中断时会自动重试，恢复后从断点继续，不需要从头上传。

重试几次仍然失败的，在传输面板中点继续即可。

### 新建文件时提示"这个名称会被内置规则忽略"？ {#ignored-name}

`.DS_Store`、下载到一半的 `*.part` 这类名称是 Keepbay 默认跳过的。用这些名称新建的文件不会显示在列表中，所以不能使用，请换一个名称。

### 按 ⌘Z 撤销不了之前的操作？ {#undo-missing}

撤销记录保存在当前浏览器标签页中，最多记最近 50 步。换到其他标签页或关闭标签页后，之前的操作无法撤销。

撤销只对您自己的操作有效。家人删除的文件不能用您的 ⌘Z 撤销，请到回收站中恢复。

打标签、删除标签、立即删除不能撤销。

### 想改一下文件夹的路径？ {#change-mount-path}

文件夹添加后路径不能改。要先在「系统设置 › 存储」中移除，再用新路径添加。

移除会删除这个文件夹的索引，文件上的标签、AI 的结果、给成员的授权也会一起删除，磁盘上的文件不受影响。重新添加后，要重新扫描、重新授权。

如果只是硬盘的挂载点变了，可以在系统中将它挂载回原来的路径，无需移除。

### 打包下载提示"一次选的项太多"？ {#zip-too-many}

一次最多选 1000 项打包下载。选择它们所在的文件夹下载，则不受此限制。

## 预览与媒体 {#media}

### 视频没有缩略图，HEIC 照片打不开？ {#ffmpeg}

这两项功能都依赖系统中的 ffmpeg，Keepbay 不附带（HEVC 解码涉及专利授权）。安装 ffmpeg 即可：

```bash
sudo apt install ffmpeg      # Debian、Ubuntu
```

HEIC 还要求 ffmpeg 7.1 及以上、带 HEVC 解码器，较旧系统的软件源中的版本可能不满足要求。

安装或升级后，在「系统设置 › 媒体处理」中点「重新检测」，无需重启，之前未处理的文件会自动补充处理。

### 所有照片都没有缩略图，提示"安全限制没有启用"？ {#sandbox}

内核不支持 seccomp，处理照片的子进程无法隔离。Keepbay 默认不在没有隔离的情况下解码照片和视频，因此不做处理。

浏览器能直接显示的图片（JPEG、PNG 等）和视频仍然可以预览，文件也可以正常浏览和下载。

部分 NAS（如群晖 DS918+、DS920+）上会出现这种情况。

内核无法更换、文件来源可信时，所有者可以在「系统设置 › 媒体处理」中打开「照样处理照片和视频」，之前跳过的照片会重新处理。原因和风险见[隐私与安全](./privacy#sandbox)。

### 某张超大的图片没有缩略图？ {#max-pixels}

像素超过上限的图片只读取尺寸，不生成缩略图，以避免数亿像素的全景图占满内存。

上限约 2.68 亿像素，在「系统设置 › 媒体处理」中可以看到，不能修改。这类图片仍然可以下载，用电脑上的看图软件打开。

### MKV、AVI 视频播放不了？ {#mkv}

Keepbay 不转码视频，只能在浏览器中直接播放 MP4、MOV、WebM 等浏览器支持的格式。

MKV、AVI 请下载后用播放器打开。转码需要大量 CPU 资源，在 NAS 上运行会很慢，所以目前不提供。

### 能看压缩包里有什么吗？ {#archive}

目前不能预览压缩包的内容。可以右键「解压到这里」或「解压到收件箱」，在后台解压。

支持 zip、tar、tar.gz、tar.bz2，不支持 rar、7z 和加了密码的压缩包。

### .doc、.ppt 打不开？ {#old-office}

Word 只支持 .docx，PowerPoint 只支持 .pptx，旧格式的 .doc、.ppt 只能下载后打开。Excel 的 .xls 可以预览。

演示文稿的预览只显示文字和图片，不还原动画和版式。

## 分享与通知 {#sharing}

### 分享出去的照片会带拍摄地点吗？ {#share-location}

不加水印的话，访客下载的是原图，照片中记录的拍摄地点也在里面。分享带拍摄地点的照片时，Keepbay 会提醒您。

在分享链接中打开「给图片加水印」（专业版），访客拿到的是不带任何拍摄信息的图片。

### 分享链接提示"只有连接同一网络的设备能打开"？ {#share-lan}

您是通过局域网地址访问 Keepbay 的，比如 `192.168.1.10` 或 `nas.local`，分享链接使用的也是这个地址，外网的用户无法打开。

请用外网能访问的域名打开 Keepbay，再创建分享链接，见[外网访问](./remote-access)。

### 能用分享链接让别人给我传文件吗？ {#share-upload}

目前不能。访客只能浏览和下载，不能上传、修改和删除。

### 别人说分享链接打不开了？ {#share-broken}

在「个人设置 › 分享链接」中找到这条链接，查看它的状态：已过期、下载次数已用完，还是已被停用。

成员创建的链接，在所有者关闭该成员的「创建分享链接」权限或停用其帐号后，也会失效。

### 收不到通知？ {#notify-missing}

请先在「个人设置 › 通知」中，点渠道的「发送测试通知」。渠道列表中会显示最近一次发送失败的原因。

再检查「接收哪些通知」中是否打开了这类通知。"后台任务完成"和"分享链接被访问"默认关闭。

收不到邮件时，请检查垃圾邮件。邮件不经过代理，请确保服务器能直接连接发件服务器。

## 升级与备份 {#maintenance}

### 网页上提示不能更新，要手动升级？ {#update-blocked}

最常见的原因是运行服务的 `keepbay` 用户不能写入安装目录，运行页面上给出的 `sudo chown -R keepbay: /opt/keepbay` 后刷新即可。

从 0.1.0-beta.3 之前的版本升级的，由于安装方式不同，需要手动升级一次，见[升级](./upgrade#blocked)。

### 检查更新失败？ {#update-check-failed}

Keepbay 要连授权中心 `huohuastudio.com` 查询新版本。

如果服务器需要经过代理访问外网，请在「系统设置 › 网络」中设置代理，或者让服务带上 `HTTPS_PROXY` 环境变量。

### 数据库备份在哪里？会备份我的文件吗？ {#backup}

默认每天凌晨 3 点后自动备份一次数据库，保留最近 7 份，放在数据目录的 `backups/` 中。

频率、份数和备份目录可以在「系统设置 › 维护」中修改。备份目录可以放到别的磁盘，但不能放在添加给 Keepbay 的文件夹里，否则成员浏览那个文件夹就能获取整个数据库。

备份内容仅包括数据库：索引、标签、整理记录、设置、帐号。

**您的文件本身不在备份范围内**，文件保存在您自己的文件夹中，请用 NAS 的快照、rsync 或其他备份工具备份。Keepbay 是网盘，不是备份软件。

### 能在网页上下载数据库备份吗？ {#backup-download}

不能。数据库中有全部的索引、帐号和设置，我们不希望它能通过浏览器直接下载。

如有需要，请在服务器上直接复制备份目录中的文件，默认是数据目录下的 `backups/`。

### 怎么用备份恢复？ {#restore}

网页上不能恢复，要在服务器上用命令行：停止服务，运行 `keepbay db:restore`，在列表中选一份备份，再启动服务。

详见[命令行](./cli#db-restore)。

### 换到新服务器后，AI 厂商的 Key 没了，两步验证也登不进去？ {#secret-key}

只复制了数据库，没有带上数据目录中的 `secret.key`。这些配置是用它加密的，密钥不同就无法解密。

将原来的 `secret.key` 复制过来并重启即可。如果原来的密钥已丢失，请重新填写这些配置，开启了两步验证的帐号用恢复码登录，远程文件夹重新填写凭据，见[远程文件夹](./remote-folders#offline)。

因此建议迁移时将整个数据目录一起复制，见[安装](./install#data-dir)。

## 专业版与 AI {#pro}

### 免费版能用 AI 功能吗？ {#free-ai}

不能。语义搜索、按画面搜图、识别图片中的文字、AI 桌面、收件箱自动整理、AI 标签、重要日期提醒，连同 AI 模型的设置，都属于专业版。

免费版里不会出现这些入口，功能对比只放在授权页。

### 激活时提示设备数已满？ {#device-limit}

一个授权码可以激活的设备数有上限。

到授权中心网站上解绑不再使用的设备，或者把它换绑为这台设备的安装 ID，再回来激活。

### 重装系统后，专业版没了？ {#reinstall-license}

全新安装会生成新的安装 ID，原来的授权证书对它无效，需要重新激活一次。这会占用一个设备名额，旧的那台请到网站上解绑。

如果是将整个数据目录原样迁移过来，安装 ID 不变，无需重新激活。

### 更新服务到期了，专业版还能用吗？ {#updates-expired}

能。专业版是永久使用的，到期的只是更新服务。

您装的版本照常使用，专业版的功能照常可用，安全修复也照常可以装。之后发布的新功能版本，续费后才能装。见[专业版](./pro#license-model)。

### 授权页显示"专业版 · 已暂停"？ {#pro-paused}

您装的版本是在更新服务截止之后发布的，专业版的功能暂停，文件和数据都保留。

续费更新服务后，在「系统设置 › 授权」中点「立即续期」；或者换回截止日之前发布的版本。

换回旧版本时，已经被新版本升级过数据库的，旧版本打不开，要先用升级前的备份恢复，备份之后的改动会丢失，见[升级](./upgrade#database)。

### 怎么把专业版转到新服务器？ {#transfer-license}

在旧服务器的「系统设置 › 授权」中点「在本机停用专业版」，再到授权中心网站上解绑旧设备，然后在新服务器上激活。

如果将整个数据目录原样迁移过去，安装 ID 不变，无需重新激活。见[专业版](./pro#devices)。

### 云端 AI 会拿我的文件去训练模型吗？ {#cloud-ai-training}

这取决于您选的 AI 厂商的数据使用政策，请查看厂商的说明。

Keepbay 方面：默认使用本地模型，不发送任何数据；您选择使用云端模型时，界面上会写明每项功能发送什么；自动整理、AI 标签、日期提醒这几项后台功能，还要再逐项允许一次。语义搜索选了云端的向量模型的，建立索引时会把文件中的文字发出去，见[语义搜索](./semantic-search#cloud-embedding)。

如果对此有顾虑，可以只使用本地模型，或在家中自行运行的 Ollama。详见[隐私与安全](./privacy#ai)。

### 提示"本月的 AI 花费已达上限"？ {#ai-budget}

已达到所有者设置的每月花费上限，下个月自动恢复。

需要的话，所有者可以在「系统设置 › AI 模型」中调高上限。本地模型不产生费用，不受此限制。

### 成员提示"还没有使用云端 AI 的权限"？ {#ai-cloud-not-allowed}

成员默认不能使用云端 AI，因为这会让他的文件离开这台设备。

所有者在成员详情中打开「使用云端 AI」即可；或者给这项功能换成本地模型，用本地模型不需要这个权限。

## 其他 {#others}

### 离线下载提示"不能下载局域网或本机上的地址"？ {#url-blocked}

离线下载只能访问公网地址，以防止他人借此访问您内网中的路由器管理页、NAS 管理页等地址。

Tailscale 的地址（100.64.0.0/10 网段）也在此列，所以离线下载连不到您 Tailscale 网络中的设备。局域网中的文件，建议直接将所在的文件夹添加到 Keepbay。

### Keepbay 会收集我的使用数据吗？ {#telemetry}

不会。程序里没有统计、遥测、崩溃上报，网页也不加载任何第三方资源。

Keepbay 在什么情况下联网、发送哪些内容，见[隐私与安全](./privacy#outbound)。

### 卸载了 Keepbay，我的文件还在吗？ {#uninstall}

在。Keepbay 不会把文件移入自己的存储，文件夹中的文件保持不变，卸载只删除程序和数据目录（索引、缩略图、设置）。

文件夹中的 `.keepbay-trash/` 是回收站，里面是您删除过的文件，确认不需要了可以一并删除。
