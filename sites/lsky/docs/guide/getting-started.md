# 快速开始 {#quick-start}

本文档适用于兰空图床付费版 2.x（Lsky Pro+）。开始安装前，请先完成购买并准备好安装包和授权密钥。

## 购买 {#buy}

如果您还没有购买，可以在[工作室网站](https://huohuastudio.com/products/lsky-pro#plans)购买付费版。也可以使用[开源版](https://github.com/lsky-org/lsky-pro)，开源版已经停止更新和支持，但现有功能仍然可用。

授权规则：

- **域名**：每个授权含 1 个域名，绑定后该域名的所有子域名也在授权范围内。需要更多域名或更换域名时，在授权中心操作，具体规则以授权中心页面为准
- **账号**：同一个账号可以拥有多个授权，购买时填写相同的邮箱，授权会归到同一个账号下
- **源码**：后端核心代码经过加密，运行环境要求见[环境要求](./requirement)；界面可以通过[主题](../advanced/theme)定制
- **使用范围**：安装包和授权只限购买者本人或所属公司使用，不能传播或转售，否则我们有权停用许可证。完整条款见[许可与免责声明](./declaration)

购买前建议先通过[演示站](https://v2.lskypro.com)、[论坛](https://bbs.lskypro.com)和 [GitHub](https://github.com/lsky-org/lsky-pro) 了解程序是否符合您的需求。

::: warning
付费版是一次付费、永久使用的数字商品，**购买后不支持退款**。
:::

## 准备 {#ready}

购买后，使用购买时填写的邮箱登录[授权中心](https://huohuastudio.com/dashboard)，在「我的授权」中下载最新的安装包、查看授权密钥，并添加要使用的域名。

::: danger
请不要泄露安装包和授权密钥。
:::

安装和维护需要以下基础：

- 通过 SSH 连接服务器并执行命令
- 安装和配置 Web 运行环境（Nginx、PHP、数据库），或者使用 Docker
- 根据日志排查简单的错误

文档中常见的命令和术语不再逐一解释。

## 获取帮助 {#help}

遇到无法解决的问题时，可以加入 QQ 交流群（731983303）或 [Telegram 群组](https://t.me/lsky_pro)提问，也可以到[论坛](https://bbs.lskypro.com)发帖。提问时请附上程序版本、安装方式和 `storage/logs` 中的错误日志。

::: tip
我们也提供付费安装和迁移服务，可以在交流群中咨询。
:::

准备好后，请先阅读[环境要求](./requirement)。
