# 角色组 {#groups}

所有用户（包括管理员和未登录的游客）都受角色组控制。通过角色组可以决定用户能用哪些储存、发件驱动、支付方式和 AI 驱动，以及上传的大小、频率和格式。

在管理后台的「角色组」页面，点击「新建」按钮即可创建角色组。表单分为「基础」「上传」「AI」「储存」四个标签页。

## 基础 {#basic}

系统中可以创建多个角色组，其中：

- **系统默认组**：新注册的用户归属这个组，只能有一个
- **游客组**：未登录的用户受这个组控制，只能有一个

默认组和游客组不能删除。用户购买套餐后，会在套餐有效期内切换到套餐对应的角色组。

每个角色组可以选择多个短信驱动、邮件驱动和支付驱动。短信和邮件按选择的顺序发送，前一个驱动发送失败时自动换下一个，全部失败才算发送失败。

「基础」标签页中还有以下权限开关：

| 开关 | 默认 | 说明 |
|---|---|---|
| 允许上传公开图片 | 开启 | 关闭后，用户上传的图片不能设为公开 |
| 允许重新执行图片处理 | 关闭 | 开启后，用户可以在图片操作栏中点击「重新处理」，见[重新处理](./handle#rehandle) |
| 允许设置相册访问密码 | 关闭 | 开启后，用户可以为公开相册设置访问密码，见[相册访问密码](#album-password) |

## 上传限制 {#upload-limits}

「上传」标签页中的字段：

| 字段 | 说明 |
|---|---|
| 最大上传尺寸 | 单个文件的大小上限 |
| 图片到期时间 | 上传的图片在这段时间后自动删除，0 表示永久保存。修改后只对新上传的图片生效 |
| 并发上传限制 | 同时上传的图片数量，1 到 20 张，超出的排队等待 |
| 每分钟、每小时、每天、每周、每月上传限制 | 各时间段内允许上传的数量，0 表示不限制 |
| 允许上传的文件类型 | 见下一节 |

:::warning
最大上传尺寸还受 PHP 的 `upload_max_filesize`、`post_max_size` 和 Nginx 的 `client_max_body_size` 限制，请确保这几项不小于角色组中的设置，否则大文件会上传失败。
:::

## 允许上传的文件类型 {#file-types-allowed-to-upload}

在「允许上传的文件类型」中勾选该组可以上传的格式。可选的格式由当前的图片处理器（Imagick 或 Libvips）决定，处理器不支持的格式无法勾选。

切换图片处理器的方法见[环境要求](./requirement#libvips)。

## 会员到期后删除图片 {#delete-photos-after-expiry}

开启「会员到期后删除图片」后，需要设置「到期后图片保留时长」（0 表示到期后立即删除）。用户通过购买套餐获得这个角色组，会员全部到期并超过保留时长后仍未续订的，程序会删除他在这个角色组期间上传的图片。

- 只针对通过套餐获得该角色组的用户，管理员手动分配的用户不受影响
- 开启前已经到期的历史会员同样会被处理，开启前请确认保留时长
- 由计划任务每小时执行一次，需要按[配置计划任务](./install#configure-schedule)设置好 `schedule:run`
- 也可以手动执行 `php artisan app:delete-expired-member-photos`

:::danger
删除的图片无法恢复。开启前请先告知用户保留时长，并确认套餐的到期规则符合预期。
:::

## 相册访问密码 {#album-password}

开启「允许设置相册访问密码」后，用户可以在相册详情页点击「设置访问密码」，为相册设置 4 到 32 位的密码：

- 密码只对公开相册生效。访客需要输入密码才能查看相册中的图片，解锁后 120 分钟内有效
- 加密相册中的图片不会出现在广场、热门标签、用户主页等公开列表中，相册列表中只显示加密标识，不显示封面
- 相册所有者和管理员查看时不需要密码；通过分享链接访问时只校验分享自身的密码

关闭这个开关后，用户不能再设置新密码，已经设置的密码仍然有效。在后台的「相册管理」页面可以按「访问密码」筛选相册。

## AI {#ai}

「AI」标签页中可以开启 AI 功能、选择该组可用的 AI 驱动，并设置每分钟到每月的使用次数限制，详见 [AI](./ai#group-settings)。

## 储存 {#storage}

每个角色组可以关联多个储存，用户在上传时可以切换使用这些储存。每个角色组至少应关联一个储存，否则该组的用户无法上传。储存的配置见[储存](./storage)。
