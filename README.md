# 工作室产品站点

Keepbay、Novaix、Lsky Pro+ 的官网和文档，基于 VitePress。

| 目录 | 站点 |
|---|---|
| `sites/keepbay` | https://keepbay.app |
| `sites/novaix` | https://novaix.cc |
| `sites/lsky` | https://www.lsky.pro |
| `packages/theme` | 共用主题 |

```bash
pnpm install
pnpm dev:novaix    # 本地预览
pnpm build         # 构建全部站点
```

需要 Node 22 和 pnpm 10。
